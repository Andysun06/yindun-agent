# 知识库演示 · 操作指引

这三个文件用来演示「本地知识库 + 脱敏 RAG」，你在隐盾里操作即可。

## 步骤
1. 打开隐盾 → ⚙ 设置 → 底部「本地知识库（脱敏 RAG）」→ **➕ 添加文档**
2. 选中本文件夹里的 3 个文件：
   - `供应商服务合同_示例.md`
   - `员工薪酬表_示例.csv`
   - `隐盾产品说明_示例.md`
3. 等待入库进度完成（会逐块脱敏后向量化）。
4. 回聊天页，**切到"思考"模式**，提问下面这些问题，截图检索回答：

## 建议提问（每个截一张图）
| 问题 | 看点 |
|---|---|
| 合同的违约金比例是多少？付款账期多久？ | 命中合同条款，答"每日万分之五 / 30 日内" |
| 乙方联系人是谁？电话和银行卡号多少？ | 答里的人名/电话/卡号会**先脱敏再还原**，体现隐私闭环 |
| 张伟的月薪是多少？ | 命中薪酬表，薪资被脱敏处理 |
| 隐盾支持哪些敏感实体脱敏？ | 命中产品说明，答 20+ 类 |

## 额外一张（可选）：入库即脱敏的证据
入库时/入库后，可进 ⚙ 知识库区看文档条目；或截审计面板里 `privacy_sensitive` 事件，佐证"真实隐私没进向量库"。

> 所有人名、卡号、金额均为虚构演示数据。
