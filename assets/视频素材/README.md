# 视频素材总目录

本目录集中存放 **4:55 产品介绍视频** 所需的全部素材。成片脚本、口播与时间轴见
内部视频脚本（不随公开仓库发布）。

> `MP4原片/` 的 8 段 1080P 原片**已随仓库同步**（单文件均 < 100MB、总计约 72MB），组内做视频的同学
> 直接 `git pull` 即可；`assets/介绍视频.mp4`（171MB）超过 GitHub 单文件 100MB 限制，仍走旧 Release，
> 不在仓库里。`图片素材/界面截图/` 已于 **2026-10-25 按 V3.6.20 亮色界面、2× 像素重拍**，供视频
> 专用（客户端 2720×1830、控制台 2560×1440；画面为界面沙盘的公开示例数据，不含真实个人信息）；
> 报告/PPT 的图源仍是 `docs/screenshots/`，两套图源在本轮不同步（见文末「维护约定」）。

## 组员拉取（视频制作）

```bash
git clone https://github.com/Andysun06/yindun-agent.git
# 已有仓库直接：git pull
```

| 用途 | 路径 | 说明 |

## 维护约定

- **界面截图只保留当前界面**：V3.6.20 起，`界面截图/` 统一为**亮色模式 + 2× 像素**
  （客户端 2720×1830、控制台 2560×1440，便于成片放大裁切）；旧版 `01b_新建会话.png`
  （旧命名对话框）、`05_高危操作审批弹窗.png`（旧 Qt 弹窗裁图）、`06_工作流面板.png`
  （工作流界面入口在 V3.6.21 已恢复，截图请使用右栏「工作流」页签的新画面）。
- 重新录屏后：MP4 按同名覆盖 `MP4原片/`（原片随仓库同步，提交前确认单文件 < 100MB）；
  GIF 同步覆盖 `docs/formal_assets/01–08_*.gif`，并按同名媒体流替换正式答辩 PPT
  （只改 `ppt/media/imageN.GIF`，不动版式），详见内部开发记录。
- `界面截图/` 由视频素材独立重拍（V3.6.21）；`docs/screenshots/` 仍是报告/PPT 的图源
  （V3.6.15/16）。**重制报告或 PPT 时，以 `界面截图/` 为准把 `docs/screenshots/` 一并换成
  V3.6.21**，避免两套图源长期漂移。
- `Logo/`、`控制端/`、`证据图/` 仍来自 `assets/icons/` 与 `docs/formal_assets/` 的上游副本；
  上游更新后重新复制。
