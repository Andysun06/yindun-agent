# 隐盾安全智能体 · 使用说明

> 面向涉密办公场景的本地化隐私防护桌面智能体 · V3.6.21
> Yindun Security Agent — 让本地 AI 更安全、更智能、更可控

---

## 一、产品简介

隐盾安全智能体是一款常驻桌面的 AI 办公助手，核心差异在于**内置内存级隐私防护**：
所有敏感信息（手机号、身份证、银行卡、密钥、病历、金额、人名等）在进入大模型之前，
会在内存中自动替换为加密占位符；模型全程只见占位符，回答返回时再自动还原为明文呈现给你。

配合文件沙箱、权限分级、命令白名单、高危操作人工审批与哈希链审计，
隐盾把"数据出网、落盘、留痕"三大泄露面逐一关闭，让你放心把涉密文档交给 AI 处理。

**典型用途**：合同/简历/病历等涉密文档的问答与摘要、本地知识库检索、
项目代码分析、办公文件创建与整理、可追溯的操作审计。

## 二、安装与启动

> 界面说明：V3.3.2 起隐盾使用 Web 界面（窗口无系统边框，**拖动顶部条即可移动窗口**、
> **沿窗口边缘拖拽可改变大小**，
> 右上角有最小化 / 置顶 / 关闭）。左侧是会话列表，中间是对话区，右侧是**可折叠的第三栏**
> （设置 / 审计两个页签）；顶栏两侧各有一个折叠按钮，收起后把空间让给对话。
>
> **三栏宽度可以自由调**：把鼠标移到会话栏右边缘或面板左边缘（会出现一条细高亮线），
> 按住拖动即可改变该栏宽度；**双击手柄**恢复默认宽度；手柄获得焦点后可用方向键微调
> （按住 Shift 步长更大）。宽度会自动记住，下次打开还是你调好的样子。范围上做了保护：
> 会话栏 200–420px、面板 300–640px，且**对话区始终保留至少 420px**——窗口变窄时优先收窄两侧，
> 再窄就自动把右栏收起来（窗口重新变宽会自动放回，这与"你自己手动收起"是两回事，手动收起不会被自动展开）。
>
> **闪发浮条（折叠模式）**：点顶栏的折叠按钮，窗口会缩成一条浮条（贴着原窗口底边、水平居中）。
> 在浮条里输入指令按回车，会**自动展开完整界面并把指令发出去**；按 `Shift+Enter` 则是**换行不发送**
> （浮条输入框最多显示两行，再多就在框内滚动）；浮条右侧常显一行状态
> （推理中…/已完成），不展开也知道有没有在跑；点浮条左侧的展开按钮或按 `Esc` 即可还原完整界面，
> 窗口会精确回到折叠前的位置与大小。适合"只想顺手发一句、不想让窗口占地方"的场景。
> **草稿不会丢**：主输入框里打好的字在折叠后会跟着进浮条，折叠期间在浮条里打的字在展开后会回到主输入框；
> 模型正在推理时按回车也不会吞掉你打的字，只会提示"正在推理中"。
>
> **置顶（悬浮于最上层）立即生效**：点右上角的置顶按钮或设置里的「窗口始终置顶」开关，
> **默认是关闭的**（V3.6.7 起：常驻最上层会挡住别的窗口），开了之后会记住，下次启动仍按你的选择。

> 马上生效，不需要重启。

### 方式 A：标准安装包（推荐日常使用）

1. 从 Release 下载 `Yindun-Setup-<版本>.exe`（本地构建产物名为 `隐盾安全智能体_<版本>_安装包.exe`）；
2. 双击安装，默认装到当前用户目录 `%LOCALAPPDATA%\Programs\Yindun`，自动创建桌面与开始菜单快捷方式，不需要管理员权限；
3. 安装包未做代码签名，首次运行若被 Windows Defender 提示，选择“仍要运行”或添加信任即可；
4. 卸载：设置 → 应用 → 隐盾安全智能体，或开始菜单里的“卸载隐盾安全智能体”。卸载会询问是否删除本地配置、聊天记录与审计数据，**默认保留**。

**数据落在哪**：安装目录下的配置、会话记录、审计日志与知识库向量数据；卸载时选择“否”即可保留，重装后继续使用。

### 方式 B：免安装单文件 exe（评委试用 / 临时机器）

1. 拿到 `Yindun-Portable-<版本>.exe`（约 160MB，单文件；从 GitHub Release 下载时为此名——资产名不支持中文；本地自行构建时产物名为 `隐盾安全智能体_<版本>_便携版.exe`）；
2. **双击直接运行**——无需安装、无需任何脚本、不需要管理员权限；
3. 首次启动约需 10~20 秒（单文件会先解压到临时目录，属正常现象），之后正常速度。
   界面底部会显示启动进度：**探测算力 → 载入模型 → 已就绪**；模型在后台载入内存（本机实测约 7~15 秒，
   首次或换模型时可能要 20~60 秒），载入完成后再提问就不会等；载入期间界面已经可以正常操作。

**出问题看哪里**：运行日志在 **exe 同目录的 `logs/yindun.log`**（按 2MB × 3 份轮转，含启动、模型载入、插件与工具调用、异常栈；敏感值写盘前已掩码）。查更细的过程可加 `--log-level DEBUG` 启动；若需要把程序内部的常规输出也一并记下（排障用），再加 `--log-capture-prints`（**默认不采集**：日志是明文落盘面，默认只记关键事件）。
**数据落在哪**：配置、会话记录、审计日志、知识库向量数据都写在 **exe 同目录**，所以请把 exe 放在可写目录（桌面、文档、便携盘均可）。
**卸载**：删除 exe 及其同目录下生成的数据文件即可，不留残余。

```bash
python run.py
```

> 首次启动若被杀毒软件 / Windows Defender 提示，选择"仍要运行"或添加信任即可
> （未签名的绿色软件常见误报，源码可自查）。

## 三、首次使用：配置一个"算力底座"

隐盾需要接入一个大模型作为算力底座。**设置按"数据边界"分成三档**——本机 / 局域网 / 公网，
你随时能看出"这个模型会把数据带到哪里去"：

| 档位 | 数据边界 | 典型形态 |
|---|---|---|
| **本机模型** | 数据不出这台电脑 | 本机跑的 Ollama（127.0.0.1:11434） |
| **局域网模型** | 数据出这台电脑，但不出企业内网 | 公司内网的推理服务 / Ollama（10.x / 192.168.x） |
| **公网模型** | 数据出企业内网；送出前内容已在本机脱敏 | 云端 OpenAI 兼容接口（https://…/v1） |

入口：点左下角**齿轮**图标 → 顶栏「**模型接入**」页（左边是三档供应商列表，右边是选中项的配置表单）。

### 方式 A：本机模型（推荐，数据全程不出机器）

1. 下载安装 Ollama：<https://ollama.com/download>（安装后服务自动运行）；
2. 命令行拉取一个支持工具调用的模型，需要知识库再拉向量模型：
   ```bash
   ollama pull qwen3.5:4b
   ollama pull nomic-embed-text
   ```
3. 回到「模型接入 → 本机模型」，点「重新检测」——检测到的模型会列出来，**点一下就切换**：
   左栏列出的本机模型（当前在用的那个带「使用中」标记）**点模型名即切换**，右侧「已检测到的模型」胶囊同样一点即切；两处的「使用中」会当场一起变。

> **性能提示**：2B/4B 本机模型适合问答、摘要、单步操作；多步骤文件整理（一次移动/改名多个文件）会明显变慢，建议换 7B+ 本机模型或局域网/公网模型。模型大小与耗时是能力上限，不是隐私机制的问题。
>
> **启动顺序不用再管（V3.6.21）**：先开隐盾、后开 Ollama 也可以——客户端在"模型不可用"时
> 会每 8~60 秒在后台自动重探一次，Ollama 起来后状态自动变成"算力就绪"，无需重启。

### 方式 B：局域网模型（公司内网的推理服务）

1. 「模型接入 → 局域网模型」→ 点「＋ 添加局域网模型」；
2. 填 **显示名称 / 模型 ID / 接口地址**（如 `http://10.0.0.8:8000/v1`），内网通常不需要 Key；
3. 点「**测试连接**」——通了会显示该端点提供的模型名，并可自动补进"模型 ID"；再点「保存」。
   > 探测是你在这页**显式发起**的动作：地址只取自输入框、不跟随重定向、4 秒超时、只读模型列表。

### 方式 C：公网模型（云端 API）

1. 「模型接入 → 公网模型」→「＋ 添加公网模型」；
2. 填名称 / 模型 ID / 接口地址 / API Key / **接口格式**，先「测试连接」再「保存」。
   示例（智谱开放平台）：`https://open.bigmodel.cn/api/paas/v4` + `glm-4-flash`；
3. 保存后在输入框下方的**模型胶囊**里选择它。

**接口格式（V3.6.21 起四种都可用）**：

| 格式 | 适用 | 说明 |
|---|---|---|
| OpenAI 兼容 Chat Completions | 绝大多数云端 / 中转站 | 默认；免 Key 中转站也可用 |
| Ollama 原生接口 | 远程 / 局域网 Ollama | 填 `http://<主机>:11434`，模型名为 Ollama 里的名字 |
| Anthropic Messages | Claude 系 | 填基础地址（如 `https://api.anthropic.com`） |
| OpenAI Responses | OpenAI 新协议 | 填基础地址（如 `https://api.openai.com/v1`） |

> **演示模型（免 Key）**：便携版/安装包首次启动会自动登记一个「隐盾自建中转站（供评委试用）」，走隐盾自制中转站（模型 Key 只在服务端，客户端零 Key）。
> 本机没有 Ollama 时首启会自动选它，评委拿到就能直接试用；中转站只接受隐盾客户端
> （门禁头 + UA），并有模型白名单与频率限制。额度有限，请勿滥用。
> 地址可用设置项 `demo_model_base` 覆盖（自建中转时用）。

> **密钥怎么改、会不会丢**：密钥存下之后**不再回显**（界面只显示「已配置」），输入框留空即
> **不动已存的密钥**——改地址、改模型名后直接再点保存即可；只有你**填了新密钥**才会替换。
> 「测试连接」在留空时也会用**已存的那把密钥**去测，不会因为输入框空着就报「密钥不被接受」。
> 想彻底清除密钥：删掉这个条目再重新添加。
>
> **隐私提示**：开启"隐私隔离网关"（默认开启）时，发往公网的内容已在本机替换为占位符，
> 真实敏感数据不出机器；密钥加密存本机、界面不回显。

### 切换模型

输入框**下方那一行**就是会话级设置（参考主流 agent 的输入区布局）：
`＋ 挂载文档 · 模型胶囊 · 思考强度 · 发送`。点模型胶囊会按三档分组列出可用模型；
思考强度是**四档下拉**（低 / 中 / 高 / 最高，对应推理轮次约 2 / 4 / 7 / 10），点一下即生效；
模型胶囊左侧还有一枚**本对话权限**胶囊（盾牌图标），管的是"这个对话让 AI 做到什么程度"——
点开可以为本对话单独设档，或选「跟随设置默认」。换模型、换档位、换权限都即时生效，正在跑的轮次不受影响。

## 四、核心功能使用

### 4.1 对话与隐私脱敏

直接在底部输入框下达指令即可。含敏感信息的内容会先脱敏再交给模型，回答后自动还原。

- **输入区**（V3.6.16，参考 ZCode 新版）：左下是「＋」挂载与**权限胶囊**（本对话生效），右下是**模型名 + 思考档位 + 方形发送键**，整体读作「本机 Ollama / qwen3.5:4b 高 ∨」；推理中模型名左侧出现小转圈，点方形停止键可随时中断。
- **模型与思考强度**：点模型名打开**单卡片**——顶部供应商（点右侧箭头展开供应商子菜单，保留本机 / 局域网 / 公网三档边界），中间是当前供应商的模型（当前项打 ✓），底部是**四档滑杆**（低 / 中 / 高 / 最高，最高档绿→蓝渐变）。拖动即保存，`Ctrl+T` 可循环；点输入区的「高」也会直接打开这张卡片并聚焦滑杆。键盘 ↑↓ 选模型、Enter 确认、→ 展开供应商、Esc 关闭。

- **对话 / 工作模式**：输入框上方切换，**默认「工作」**。
  「对话」只回答简单问题，不读取本机文件、不检索知识库、不调用任何工具；遇到需要真实世界信息的问题，
  会直接提示你切到「工作」。
  「工作」支持完整工具调用与多轮推理，推理强度在输入框下方的「思考」四档控件里随手调（低 / 中 / 高 / 最高）；
  写盘、删除、执行命令仍按权限档逐次审批。
- **AI 权限四档**：设置页「隐私与权限 → AI 权限模式」是**新对话的默认档**，四档配一张能力对照表（读取一律放行，差别只在写盘 / 删除 / 执行命令）；
  每个对话还可以在输入区的权限胶囊里**单独设档**（例如"整理资料"这个会话放到自主模式、"改代码"那个会话留在变更前确认），覆盖值随会话保存，切回该会话仍在；选「跟随设置默认」即清除覆盖。
  计划模式只读分析、不做任何变更；变更前确认为默认档（写盘 / 删除 / 命令前逐次确认）；自主模式在沙箱内自动写盘、删除与命令仍需确认；
  完全访问在沙箱内连删除也自动放行。★ **执行命令在任何档位都需要你确认**，系统目录与凭据文件（`.ssh`/`.aws`/`.env`/`id_rsa`）的拦截与档位无关。
  切换档位**下一个操作就生效**，不需要重启。
- **严格模式（可选，收紧命令执行）**：设置页「隐私与权限 → 允许执行本地脚本」关闭后，
  命令执行禁用 Python 等解释器，仅保留只读命令（git 只读 / echo）；需要跑脚本的办公流程再打开。
  无论开关如何，命令都在进程容器内执行（超时会终止整棵进程树），且每次执行仍需人工审批。
- **整理文件**（V3.6.8 起可直接指挥）：移动、复制、改名、**批量改后缀**、建目录都有对应工具——
  例如「把桌面上所有 `.jpeg` 改成 `.jpg`」「把这个文件夹里的报告移到 D 盘存档」「帮我建一个 `素材/截图` 目录」。
  ★ 默认可读写范围 = 程序目录 + 你的**桌面 / 文档 / 下载**，所以这些日常操作不再被当成越界；
  写盘类操作仍按当前权限档走（变更前确认档会先弹窗给你核对）。两条安全约定：**目标已存在时默认拒绝覆盖**
  （要覆盖得明确说"覆盖"）、**批量改名遇到重名会整批拒绝**（不会改一半）——工具会把原因和下一步写清楚。
- **挂载文件**：点「＋」挂载文件，直接在对话中就其内容提问。**能读到什么格式**（V3.6.7 实测）：

  | 类别 | 格式 | 模型能拿到 |
  |---|---|---|
  | 文档 | PDF（文字版）、Word `.docx`、PPT `.pptx`、Excel `.xlsx` / `.xls` | ✅ 正文/表格/幻灯片文字（PDF 与 PPT 会标出页码） |
  | 文本家族 | `.txt/.md/.csv/.tsv/.json/.html/.log/.yaml/.xml/.ini/.conf/.rst` | ✅ 原文（自动识别 UTF-8/GBK 等编码） |
  | 图片 | `.png/.jpg/.bmp/.tif/.webp` | ✅ **用 Windows 自带 OCR 读出图上的文字**（离线、不下载模型、一张截图约 0.05 秒；结果里会标注引擎并提示可能存在误差）。非 Windows 或系统缺中文语言包时，会明确告诉你「需要 OCR 组件／请给文本版」，**不会假装读到了** |
  | 扫描件 PDF | 图片型 PDF | ✅ 同上：逐页渲染后走 OCR 出字（页码照旧标出） |
  | 音频 | `.mp3/.wav` 等 | ❌ 本版**不支持**（转写引擎未随包提供，界面会如实说明） |
  | 压缩包 / 其它二进制 | `.zip`、未知格式 | ❌ 明确提示"请先解压/请提供文本版" |

  上传后每份附件在输入框上方有一个胶囊：读出多少字、是否失败、失败原因、解析来源（内核/插件）
  都会显示；读不出来的会**标红并写清原因**。长文档不会一股脑塞给模型——超出预算的部分改为
  按题号/关键词检索（模型会自己调 `read_attachment_chunk` 去取），这是为了让小窗口的本地模型
  也能处理长文档而不被截断。
- **会话管理**：💬 切换历史会话，➕ 新建会话；多会话相互隔离，记录加密存储。
- **长回答不会半句截断**（V3.6.16）：模型单次生成长度用尽时，界面会自动从断点**接着写一次**并把两段拼成完整回答；如果续写后仍到上限，会明确提示「回复『继续』即可接着写」，不会把半句话当成已完成。
- **请求用途红线**（V3.6.16）：如果指令是「收集/整理个人信息 + 出售、转卖、变现」，智能体会**直接拒绝**（不调用模型、不产生任何文件操作、写入审计）；如果是「收集个人信息 + 发给他人/上传/公开」，仍可在本机整理，但审批弹窗顶部会出现红色用途警示。整理自己的资料（如备份通讯录）不受影响。

### 4.2 本地知识库（脱敏 RAG）

在设置页底部"本地知识库"区，点"➕ 添加文档"将机密文档入库（入库即逐块脱敏，
向量库中只存占位符，真实隐私永不落盘）。之后在对话中即可语义检索问答。
**入库支持的格式与上表同一套解析器**（文档 / 文本家族 / 图片 / 扫描件都走同一条 OCR 通路 ✅，
音频与压缩包不支持）；**哪一篇没进库、为什么**都会当场列出来，不会静默少收录。
单文件上限 **50MB**；同名文件重复导入以最新一次为准。

- **知识库只答本机/本单位资料**（V3.6.16）：合同、报表、规章、已上传文档这类问题会先检索知识库；算法、原理、代码、研究类**通用知识**问题由模型直接推理，不会被拽去查库。
- **检索结果给的是片段，不是全文**：每段约 500 字（相邻片段有 50 字重叠），界面/回答里会明确标注「这是检索命中的片段」；相关度按距离换算，命中过弱时会直接说明「知识库里没有这条」，不拿无关片段硬答。
- **同一轮不会反复检索、反复弹审批**：相同查询会复用已有结果；第二次起会提示模型停止重复检索，直接基于已有内容作答。

### 4.3 协同工作流（V3.6.21 恢复入口）

右栏「工作流」页签提供四个内置模板（合同审查 / 周报生成 / 代码安全检查 / 数据处理流水线）：

1. 选模板 → 填数据目录（留空＝当前可读写范围）→ 点「启动」；
2. 面板显示实例与步骤状态，点「执行下一步」推进；
3. 遇到**内核强制人工审批**的步骤（写盘 / 删除 / 执行 / 导出）时，面板会出现「通过 / 驳回」，
   点「通过」才继续——审批记录写入审计；
4. 完成后点「导出执行记录」，得到一份「步骤 / 状态 / 工具 / 结果摘要」的 Markdown 表。

> **边界（如实声明）**：这是**线性流程**，没有分支 / 回退 / 单步重跑；开放任务（写材料、查资料、
> 改代码）不建议塞进固定流程。V3.6.7 曾移除入口，V3.6.21 按"内核能力完整、审批链路已修通"的
> 复测结论恢复，只暴露引擎真实有的操作。工作流实例会落盘，重启后仍可继续审批。

### 4.4 审计黑匣子

点左下角审计图标打开审计黑匣子：LLM 输入输出、工具调用、脱敏还原、审批决策逐条留痕，
哈希链完整性状态实时可见，可导出 JSON / HTML 审计报告；面板内还提供「隐私健康体检」与「模型行为画像」。
启用「导出格式扩展」插件后，导出菜单还会多出"Markdown 表格 / 卡片式 HTML"两种格式（菜单里会标明来源）。

**关于"链校验未通过"**：校验未通过时面板会直接写出**原因**（例如"尾部被截断""锚点缺失"
"第 N 条出现未受保护的旧版条目"），不是只给一个红叉。若原因是**锚点缺失**——通常出现在
从旧版本升级、或把审计目录拷到另一台机器之后——面板会给出「重建锚点（接受当前链）」按钮：
点它表示**你确认接受当前这份链作为新的信任起点**；确认之后，此前发生的尾部截断将无法再被发现，
所以请先确认这份链确实没有被裁剪过再点。

### 4.5 插件（按需扩展能力）

设置页「插件（能力扩展）」区列出内置与用户安装的插件，默认全部关闭，需要时打开开关即可。
每个插件卡片会写清：**它提供了什么能力**、来源（内置/用户安装）、网络/文件权限、依赖是否满足。

**怎么确认插件真的在工作（三个证据，卡片里直接可见）：**

1. **运行状态行**（卡片顶部）：显示"已触发 N 次 · 最近时间 · 正常/出错"。
   - `等待触发` = 已启用但还没遇到对应场景（如"审批决策提示"要等审批弹窗出现才运行）；
   - `未启用` = 开关没打开；
   - `出错：…` = 最近一次运行失败，原因直接写在卡片上。
   > 说明：运行状态只统计"实际被调用过"的次数——不写日志、不猜，有没有干活一眼可见。
2. **效果证据**：插件生效时结果会出现在具体位置——审批弹窗里的提示行（标注了插件名）、
   导出菜单里的插件格式、工作流面板的模板列表里的"插件提供"来源标注。
3. **审计记录**：启用/停用与配置改动都会写入审计页，可随时回溯。
   如果怀疑"启用了却没反应"，点「插件自检」——钩子函数缺失这类问题会被直接报出来。

- **自定义敏感词表**：把项目代号、内部称谓、专用术语纳入脱敏。编辑词表文件，每行一条：
  普通词按字面匹配，`re:` 开头按正则，`#` 开头是注释。命中后送模型的是占位符，还原仍只在本机完成。
- **扩展附件解析**：让 `.eml` / `.html` / `.mht` 也能当附件挂载（纯标准库解析，不联网），
  解析出的文本与内核路径一样先脱敏再送模型。
- **办公工作流模板包**：给工作流补两个模板（代码安全体检增强版 / 本周工作总结）。
  其中"导出报告"这类高危步骤的审批由**内核强制**，插件无权降低审批强度。
- **导出格式扩展**：审计报告导出 Markdown 表格、工作流报告导出卡片式 HTML。
- **审批决策提示**：审批弹窗出现后，用本地模型判断"这次操作与你刚才的请求是否相符"，结论异步补发到弹窗，仅供参考。
- **laya 风险分级**：审批弹窗再补一行风险分级（高危/中危/低危）。
  **接入三步**：① 命令行 `pip install laya`（约 2~3GB，含 torch；仅源码运行模式可接入，
  打包版 exe 因环境隔离无法加载，会自动使用正则回退）；② 设置页打开该插件开关；
  ③ 首次触发会联网从 Hugging Face 下载模型权重（涉密环境请预先离线导入），
  下载期间插件只等 25 秒就先用正则规则给出提示，权重就绪后自动切换为模型打分。
  没装 laya 也完全可用——自动回退到正则规则分级，默认规则开箱自带，`risk_rules.txt`
  可在设置页直接编辑、改动立即生效；`backend.txt` 可强制只用模型或只用正则。
  无论哪条路径，提示都写明本次来源。

安全说明：插件是**本地代码**，隐盾不会联网下载插件（laya 是你要自己安装的第三方 Python 包）；启用/停用、词表改动都会写入审计。

> 想自己写插件？见 [插件开发.md](插件开发.md)：钩子契约、安全边界与最小示例都在里面。

### 4.6 企业控制面（员工机自助接入 + 管理员集中管控）

**员工侧（三步，不需要管理令牌）**：向 IT 要一个 **6 位配对码** → 「设置 → 企业控制面」填
控制面地址 + 配对码 → 点「接入」，然后打开"上报"开关并（可选）打开"定时同步"。
接入后本机只上传**掩码事件与元数据**；控制面下发的策略**只收紧**，已生效的规则会逐条列在这页，
也可以显式撤销。断开上报**不会**自动移除已下发的规则（避免"悄悄放松"）。

**控制台侧**：顶栏「配对码」生成一次性码；端点表显示**在线/失联**与**策略待同步**；
「导出 CSV」把掩码审计导出来（合规留档，Excel 直接打开）。

**对话流里看得见过程**：思考（带耗时）、工具动作（名称/目标/结果）、以及**关键判定**——
隐私隔离网关识别了哪些实体、laya 风险分级的结论等，都直接显示在对话流里，不只在审批弹窗一闪而过。

### 4.6 控制面（企业侧集中管理，运维用）

给 IT/安全管理员用，普通使用者不需要碰。**默认关闭**——集中管理是显式选用的能力，程序绝不静默上报。

**在管理机上启动控制面：**

- **便携版（推荐）**：双击 `dist/隐盾控制端_<版本>_便携版.exe` → **直接打开一个控制台窗口并自动登录**，
  不需要抄地址、也不需要手输令牌（令牌仍保护远程访问；窗口只在本机回环打开，且页面会立刻把它从地址栏抹掉）。
  关掉窗口即停服。**exe 不再带命令行黑窗**（V3.6.7 起）：启动信息（监听地址、数据目录、令牌文件路径）
  写在 exe 同目录的 `logs/yindun.log`；若启动失败（例如端口被占），会弹一个系统对话框写明原因与日志路径——
  不会出现"双击了却什么都没发生"。已经有一个控制台在跑时，再双击会**明确提示「已经在运行」并退出**
  （避免两个实例抢同一端口，让你看到旧版本的界面）：请用已经打开的那个窗口，或先在任务管理器里
  结束旧的 `隐盾控制端…便携版.exe` 进程。
- **源码/服务器**：

```bash
python -m yindun.control              # 起服务 + 开桌面窗口（默认）
python -m yindun.control --no-window  # 只起 HTTP 服务：装到服务器上、由别人用浏览器访问
python -m yindun.control --browser    # 不弹窗口，用系统默认浏览器打开
python -m yindun.control --host 0.0.0.0 --window yes   # 对外监听（默认不弹窗口，需显式要求）
```

**管理令牌**在 `control_data/admin_token.txt`（数据库里只存哈希）。远程用户用浏览器打开
`http://<控制面>:8787/`，粘贴令牌即可进入（令牌只留在当前标签页，关闭即清除）。

**让别人的机器连进来（例如和同学组局域网一起看）：**

1. 控制台右上角点「**配对码**」→ 打开浮窗。里面有三件事：当前配对码（可**自定义**成好念的串，如
   `BANJI-2026`；也可一键重新生成）、有效期、以及**局域网地址**（如 `http://192.168.96.148:8787/`）。
2. 浮窗里打开「**允许局域网访问**」开关。控制端默认只监听本机（`127.0.0.1`），**不打开这个开关，
   别人一定连不上**——这不是网络问题、也不是配对码问题。打开后监听立刻切换，**不用重启程序**，
   端口不变（别人抄走的地址不会失效）。
3. 如果 Windows 防火墙弹出询问，**必须选「允许访问」**；没弹或之前拒绝过，需要到防火墙里放行
   （否则地址对、码对，照样连不上）。
4. 把「地址 + 配对码」发给对方：对方浏览器打开地址 → 输入配对码即可进入（配对码**用后即作废**，
   一张码给一个人）。装隐盾客户端的机器则在「设置 → 企业控制面」里填地址与配对码自助接入。
5. 不用了就关掉开关（切回仅本机）；局域网地址随即可连不上——这是真关，不是只改显示。

> 装着 VMware/VirtualBox 或内网穿透的机器会列出多个地址，**优先用第一个**（通常是 WiFi/热点的），
> `192.168.x.1` 这类多为虚拟网卡，别人连不上。
> **安全边界**：局域网监听默认**未启用 TLS**（本机调试可以）；要让同事的机器接入，
> 启动时加 `--tls-auto` 一键生成自签证书并启用 TLS，或提供自己的证书；只在你自己可信的局域网里用（手机热点、宿舍网这类），
> 不要在公共 WiFi 上长期开着；配对码一次性、管理令牌不要外发。若要长期对外提供服务，
> 也可用 `--tls-cert/--tls-key` 提供正式证书（≥1.2），或在 §4.6 的命令行方式下挂 TLS 反向代理。

控制台六页：**态势总览**（在管端点 / 事件总量 / 高危事件 / 链告警 + 链锚定状态 + 告警流）、
**统计分析**（近 14 天趋势柱图，深色段为高风险；事件类型 Top 12；级别构成；端点活跃度；近 7 天与环比）、
**事件台账**（按端点/类型/级别/关键词检索）、**端点资产**（版本、链长、模型、插件、严格模式、生效策略）、
**策略下发**（只提供"收紧"语义的四类输入）、**模型用量**（调用计数与交互体量，不含内容）。
统计口径全部在服务端聚合（界面只拿到分页事件，自己算总数会对不上），缺事件的日期补 0 柱，
横轴按真实天数铺满——不会把"周末没人用"画成"一直在涨"。
支持明暗双主题、10 秒自动刷新、`/` 聚焦搜索、`1`~`6` 切页、`R` 刷新。

**在员工机器上接入（端点侧）：**

1. 在控制台所在机器上登记端点（需要管理令牌），拿到**端点令牌**与**策略签名密钥**：

   ```bash
   curl -X POST http://<控制面>:8787/api/v1/enroll \
     -H "Authorization: Bearer <管理令牌>" -H "Content-Type: application/json" \
     -d '{"name":"财务部-27号机","endpoint_id":"ep-fin-27"}'
   ```

2. 把返回的两个值写入端点配置并启用（`ControlReporter.configure(url, endpoint_id, token, policy_key)`；
   令牌会加密落盘）。此后每次上报成功或失败都会写入**本地审计**（事件类型 `control_report`），
   使用者可在审计面板看到"什么离开了这台机器"。

**三条边界（选它之前请先读）：**

- **控制面拿不到明文**：它收到的内容 = 端点本地审计落盘的内容（敏感路径已掩码为占位符）；
  映射密钥由端点 DPAPI 托管，控制面即便拿到映射表也解不开；模型提示词与回答从不经过控制面。
- **策略只能收紧，不能放行**：可下发项只有 敏感路径（并集）/ 审批下限（取更严）/
  允许的模型与插件（交集）/ 强制严格模式；`anonymize`、`bypass`、`auto_approve`、`whitelist`、
  `disable_audit` 这类键会被**整包拒绝**——端点被攻破最多让端点管得更严，放行不了任何操作。
- **不是系统级 DLP**：只覆盖隐盾自己经手的文件与命令事件，不监控整机行为；也不代理模型流量。

> 现状声明（V3.6.21）：默认只监听回环；**三角色 RBAC**（admin / operator / viewer，命名令牌可吊销、
> 明文只下发一次）；**速率限制默认开启**（600 次/分钟/IP，`--no-rate-limit` 可关）；
> **TLS 可一键自签**（`--tls-auto`）或提供正式证书。仍缺**多租户隔离**与**证书轮换**；
> 端点侧 30 秒定时同步与策略落内核已接通。多组织共用一套控制面前，请先补这两项。

### 4.8 插件：市场里开关，设置栏里配置

设置页「插件」只管两件事：**有哪些插件、开不开**。页面顶部是搜索框，下面按分类（安全 / 文档 / 办公 / 导出）
排成双列卡片，每张卡片是**拼图图标 + 名称 + 版本 + 一句话 + 启用开关**；点「⋯」展开详情可看
**运行状态**（是否真的被触发过）与**能力清单**。

**插件的配置不在这里改**，而是各归各位：

1. 打开某个插件的开关（启用）；
2. 如果它有专属设置（例如「自定义敏感词表」的词表、「laya 风险分级」的三级接入），
   左侧设置栏会**新出现「插件」分组与它的栏目**，进去才是它的设置正文；
3. 关掉开关：栏目立刻隐藏，插件能力同时被收回（不是"界面藏起来、实际还在跑"）。
   如果当时正停在它的设置页，会自动退回插件页并提示。

插件只能做加法：补充识别、扩展解析、工作流模板、导出格式；脱敏豁免 / 白名单 / 审批放行 / 审计写入永不开放。

### 4.9 laya 风险分级（可按数据边界分三级接入）

先到插件页**启用「laya 风险分级」**，左侧设置栏的「插件」分组里就会出现它——
这是 laya 的接入页，与「模型接入」同一套思路——**同一能力，不同数据边界**：

| 档位 | 数据边界 | 需要准备什么 |
|---|---|---|
| 本机 laya 模型 | 数据不出这台电脑 | 本机装好 laya（`pip install laya`，依赖 torch）；首次可能需联网下载权重，涉密环境请预先离线导入 |
| 局域网 laya 服务 | 出机器、不出企业内网 | 公司内网部署的 laya 服务，暴露一个 OpenAI 兼容端点（`/chat/completions`） |
| 正则规则（回退） | 全离线 | 什么都不用装，规则可在本页直接编辑 |

页面顶部会显示**当前实际生效的是哪一级**与最近一次分级的来源；选中某一级后右侧是它的配置表单：
本机档可以「重新检测」，局域网档填地址与模型名后可以「**测试连接**」（只读探活）与「**试打分**」
（真发一次分级请求并把结果回显给你看——"能连上"和"能分级"是两件事，页面不会把前者说成后者）。
无论哪条路径，审批弹窗里的提示都会写明**本次来源**。laya 只影响提示文字，**不参与放行判定**。

### 4.10 本版修复要点（V3.6.17）

这一版是针对独立测试报告 12 条缺陷的修复批次，使用上能直接感知的变化：

- **用途红线更准**：正常说法「把买进卖出的客户名单做成表格」不会再被拒绝；
  「把客户资料拿去交易 / 帮我买卖这些客户名单」会稳定拒绝；「银行卡交易流水」不受影响。
- **对话模式边界更清楚**：「这份文件是什么时候被删除的？」这类需要读文件的问题，会提示切到「工作」；
  「帮我把文件保存到桌面，可以吗」也会提示切到「工作」后再走审批，不会假装已经执行。
- **知识库只为本机资料检索**：算法、代码、架构、Excel 操作这类通用题不再被强制检索；
  「上个月报销了多少」这类业务问题会正常走知识库。
- **长回答续写不丢前半段**：续写轮即使转而调用工具，已生成内容也会保留并合并。
- **知识库占位符还原更完整**：模型把占位符写成 `KB_NAME_1_b7c2`、`[kb_name_1_b7c2]`、
  `【KB_NAME_1_b7c2】`、`[KB-NAME-1-b7c2]` 都能还原；仍有歧义时保留占位符并如实提示，不猜值。
- **界面与窗口**：状态行统一显示「推理 N/M」；思考强度滑杆可用方向键调档；
  审计链校验失败自动展开时能看到完整记录；最大化状态跟随系统还原，最大化不再盖住任务栏，
  失败提示按真实原因分档。
- **审批超时**：5 分钟无响应会停止整轮，不会在无人值守时继续调用工具；
  同一轮被驳回的操作不会自动重试；知识库检索的审批卡显示检索词而不是项目目录。

### 4.11 上下文窗口与长回答（V3.6.18）

- **上下文窗口按模型走**：本机 Ollama 会自动探测真实窗口，再按本机 `num_ctx` 上限（32k）折算；云端模型按你填写的「上下文窗口」或模型家族估值（未知 16384）。设置页「模型接入 → 编辑模型」新增了「上下文窗口」字段，可显式填写。
- **长回答不会被悄悄截断**：单次生成达到上限时，先自动从断点**续写一次**；仍超就请模型重写一份**不超上限的精炼版**；两种都失败才会在末尾提示「回复『继续』」。不会再把半张表格当成完整回答。
- **供应商子菜单**：模型卡片点供应商时，子菜单**向左**展开，不会把窗口右侧顶出空白。

### 4.12 控制面上报、只读登录与快捷键（V3.6.19）

- **上报即时性**：打开「上报」后会自动开启 **30 秒**定时同步；状态显示「已连接 · 待同步 N 条 · 上次同步 时间」，不再笼统写「上报中」。
- **角色令牌（V3.6.21）**：除管理令牌外，可创建命名角色令牌（`POST /api/v1/tokens`，仅 admin）：
  `admin` 全部操作、`operator` 端点登记/策略下发/配对码、`viewer` 只读。明文只在创建时返回一次，
  可用 `DELETE /api/v1/tokens/<id>` 立即吊销；`viewer_token.txt` 里的引导只读令牌仍然有效。
  若提示令牌无效，请确认复制的是文件里的**第一个非注释行**。
- **控制台只滚动一次**：内容区与侧栏各自滚动，外层页面不再出现第二条滚动条。
- **Ctrl+Enter 换行**：主输入框与闪发浮条都支持 Ctrl+Enter（或 Cmd+Enter）换行，Enter 才是发送。

### 4.13 暗色主题下的判定行与插件标签（V3.6.21）

- 暗色模式下，「隐私隔离网关 / 对话模式限制」这类关键判定行与插件标签、通过态徽标统一使用**暗绿底 + 亮绿字**，不再出现白底卡片。
- 浅色主题的配色保持不变；切换主题后无需重启，已有的会话记录会按当前主题重新渲染。
- 若仍看到白底，说明运行的是旧版客户端（V3.6.19 及以前），请换用 V3.6.21。

## 五、安全机制说明

| 机制 | 作用 |
|---|---|
| 隐私脱敏网关 | 30 类敏感实体识别（正则粗筛 + 程序化精验；V3.6.21 新增固话/混淆邮箱/卡面数字），进模型前占位符化，映射表 Fernet 加密、密钥 DPAPI 保护 |
| 还原与审计口径 | 回答返回前把占位符换回真值：① 精确匹配；② 模型丢了方括号时按「类型 + 随机码」**容错还原**（不唯一就保留占位符，绝不猜错值）；未能还原的处数会在回答里如实提示，审计也只统计**真的替换掉**的条数（不拿映射表条数充数）。 |
| 文件沙箱（可读写范围） | 沙箱是**默认可读写范围**（设置页「隐私与权限 → 可读写范围」可改）。**默认范围 = 程序所在目录 + 你的桌面 / 文档 / 下载**（V3.6.8 起；这三个目录按系统外壳的真实路径解析，OneDrive 重定向过的机器也能认对。显式选了目录就**只认它**）。**范围内的操作**按当前权限档走，不受额外打扰；**范围外**（例如 D 盘某个资料目录）不再一刀切拒绝，而是**按档位判定**——计划档拒绝、变更前确认档逐次弹窗（显示完整真实路径）、自主/完全访问档放行，**并且每一次范围外操作都写进审计**、工具结果里也会明写「本次操作在可读写范围之外：<路径>」，对话流里看得见。**与档位无关的硬地板**：系统目录（如 `C:\Windows`）任何档位都拒绝，凭据/密钥类路径仍需确认。符号链接/junction 逃逸照旧拦死（realpath + commonpath 双校验） |
| 权限四档 | 计划模式 / 变更前确认 / 自主模式 / 完全访问：决定「要不要人工确认」，覆盖**本机文件操作**与**可读写范围之外**的操作（后者一律额外留审计）。**不决定底线**——执行命令四档皆需确认（计划模式拒绝）、系统目录 deny 与凭据路径 confirm 与档位无关、控制面与自定义规则只能更严 |
| 命令白名单 | 放行 python/pip/git/echo，去 shell 化执行，并做子命令级收口：python 仅允许执行**沙箱内**的 .py 脚本（`-c`/`-m`/标准输入等内联代码一律拒绝；脚本路径经 realpath 校验，符号链接/盘符相对路径等越界形态拒绝；子进程只保留基础环境变量）；pip/git 仅允许只读子命令；审批弹窗会展示脚本内容预览，供放行前核对。命令在**进程容器**内执行（Windows Job Object：超时/应用退出即终止整棵进程树，进程数上限 64），并可在设置页开启严格模式直接禁用解释器。**边界说明**：这是策略层控制 + 进程容器，不是完整 OS 级沙箱——放行的脚本仍以当前用户权限运行 |
| 熔断审批 | 高危操作挂起后台线程，弹窗展示申请工具、目标路径与即将执行的命令 / 即将写入的内容，人工二次确认后才放行；超时自动驳回。V3.6.16 起，审批建议先显示「正在研判」占位，结果异步补上，弹窗不再抖动 |
| 请求用途合规（V3.6.16） | 在模型与工具之前做**确定性**用途判定：收集/整理个人信息 + 出售/转卖/变现 → **直接拒绝**（不调用模型、不产生任何工具操作、写审计）；收集个人信息 + 发给他人/上传/公开 → 允许本机整理，但审批弹窗顶部显示**红色用途警示**。审批弹窗里的「操作意图预判」（可选插件）先说明意图/数据/去向，再让「是否相符」「操作风险」两条建议发言；后两条在红线命中时不再给出「相符」「低危」这种可能被误读为背书的结论 |
| 哈希链审计 | HMAC-SHA256 链式存储，篡改即告警；另设 HMAC **链锚点**（条数+链头，存放于密钥旁的用户目录）以发现"整链改写"与"尾部截断"；审计自身只存脱敏预览 |

## 六、数据与隐私

- **控制面（可选，默认关闭）**：`control_data/`（控制面自己的数据：SQLite 库、管理令牌明文文件）。
  端点的上报配置在 `config/control.json`，其中令牌与策略签名密钥**加密落盘**。
  ⚠ 启用前请确认数据边界：控制面看到的内容**等于端点本地审计落盘的内容**（敏感路径已掩码），
  映射密钥始终留在端点（DPAPI 绑定），控制面**无法还原明文**；模型提示词与回答**不经过控制面**。
- **配置**：程序目录下 `global_config.json`（模型、权限、界面等；免安装版即 exe 同目录）。
- **会话**：`chat_sessions.json`，内容加密存储；附件全文同样以密文段存储，**删除会话即连同其附件快照一并清除**（启动时也会把历史遗留的明文会话主动重写为加密存储）。
- **审计**：`audit_logs/`，哈希链防篡改，仅存脱敏预览。
- **知识库**：`data/knowledge_base/`，只存占位符向量（元数据只留文件名，不写本机路径）。
- **用户目录**（`%APPDATA%\Yindun\`）：只有两样东西——脱敏主密钥（Windows DPAPI 按当前用户保护）
  与**审计链锚点**（`audit_chain.anchor.<审计目录指纹>.json`，用于发现"整链改写/尾部截断"）。
  这两样刻意放在用户目录而不是程序目录：**不能与它们要保护的数据同盘**，否则"删掉密钥/锚点"
  就能绕过保护。也因此它们不随 exe 移动（换机器后旧审计链需要重新确认，见 4.4）。
- 免安装版：删除 exe 与其同目录生成的数据即可；如需彻底清除，再删除上述用户目录下的 `Yindun\` 文件夹。
- 安装版：卸载时询问是否删除程序目录数据，**默认保留**；选“是”或手动删除 `%LOCALAPPDATA%\Programs\Yindun` 才会清除；用户目录同上。

## 七、常见问题（FAQ）

- **状态栏显示"模型初始化失败"**：未装 Ollama 或未拉取模型，按第三节方式 A 完成，或改用方式 B。
- **杀毒软件报警**：未签名绿色软件常见误报，添加信任即可。
- **想让 AI 写文件却提示"对话模式无法执行"**：把顶栏模式切到「工作」再试。
- **回答里出现 `[PHONE_0_xxxx]` 这类占位符没还原**：属跨轮历史占位符，正常会随会话映射还原；
  若长期不还原，可在设置页关闭再开启"隐私隔离网关"重置会话。
  ★ 若模型把占位符改写成不带方括号的裸形式（例如写在反引号里），内核会**按类型 + 随机码做容错还原**；
  只有当对应关系不唯一时才保留原样，并在回答末尾如实写「有 N 处占位符未能还原」——宁可不还原，也不猜错值。
- **知识库导入 Excel/PDF 提示「入库完成」但列表还是空的**：本版起不会再出现——入库结果按**真实统计**
  显示（「成功 x/y」），失败的每一个文件都会在知识库列表上方**一直显示原因**（例如「Ollama 未在线、
  没有拉取 nomic-embed-text」）。如果「添加文档」是灰的，说明本机 embedding 还没就绪，按提示先
  `ollama pull nomic-embed-text`。
- **让它生成 Word / Excel / PPT 文件**：直接说「创建一个 aaa.docx，把内容写进去」即可，内核会生成**真正的**
  Office 文档（Word / WPS / Excel 能直接打开，不是改后缀的文本）；在已有文档上追加或替换内容也仍然可打开。
  若本机缺少生成组件，会如实告知并建议改用 .txt，**不会**产出一个打不开的假文件。
- **写进文件的内容里出现 `[PHONE_0_x]` 这类占位符**：属异常——正常会在落盘前还原成真值（跨轮掩码也支持）。
  若真的还原不了，回答与状态行都会明确写「有 N 处占位符未能还原」，可在审计面板核对本轮映射。
- **回答只有半句话就显示"已完成"**：本版起内核会识别这种"刚起头就断掉"的输出（很短、且没有句末标点），
  自动让模型**重写一遍完整回答**；重写后仍是断句时，回答末尾会明确标注「模型这次输出疑似被截断」并建议换更大的模型——
  不再把半句话当作正常完成。
- **换了电脑/重装系统后旧会话无法还原明文**：脱敏密钥绑定 Windows 用户账户（DPAPI），
  属安全优先于可恢复性的既定设计。
