# 评审指南 · 隐盾安全智能体 V3.6.21

> 面向评审老师：5 分钟上手与验收路径。**没有本地 Ollama 也能直接试用**（内置演示中转站，免 Key）。

## 一、方案概览

大模型进入办公场景的矛盾是：**数据越敏感，越需要模型能力，也越不能让它跨出本机**。
隐盾把"安全"从使用约定下沉为架构约束：

- **模型侧拿不到明文**：内存级脱敏网关先把敏感值换成 `[PHONE_0_x]` 占位符，映射表 Fernet 加密、
  密钥由 Windows DPAPI 保护；模型看到、收到的都是占位符，回答返回时在本机还原。
- **物理副作用受控**：文件操作限定在「默认可读写范围」（程序目录 + 桌面/文档/下载），
  越界按四档权限判定并写审计；命令走白名单 + 子命令校验 + Job Object 进程容器；
  高危操作一律人工审批，审批卡展示完整路径/命令/待写入内容。
- **事后可追责且自身不泄露**：HMAC-SHA256 哈希链 + 外部锚点，六类删改手法可检出；
  审计只落脱敏预览，导出同样过掩码。

## 二、快速开始（约 3 分钟，无需 Ollama）

1. 下载 `Yindun-Portable-v3.6.21.exe`（Release 资产），双击；
2. 首次启动会弹提示：「演示版本：已内置『隐盾自建中转站（供评委试用）』…」；
3. 输入框下方模型胶囊里选 **隐盾自建中转站（供评委试用）**，直接提问即可。

> 演示中转站：模型 `deepseek-v4.1-flash`，模型 Key 只在服务端；只接受隐盾客户端
> （门禁头 + UA），有模型白名单与频率限制。地址 `https://yindun-relay.pages.dev/api/ai`。
> 额度有限，请勿压测。正式使用请接入自己的模型（本机 / 局域网 / 公网三档）。

## 三、5 分钟体验路径

| 步骤 | 操作 | 预期现象 |
|---|---|---|
| 1 | 挂一份 docx，输入「只根据附件回答：联系人是谁？联系电话多少？合同金额多少？」 | 绿色判定条：识别到哪些实体、替换成什么；回答里真实值已还原 |
| 2 | 确认顶栏是「工作」（默认即是；「对话」只做简单问答、不调工具），再让它「在桌面创建一份周报.txt」 | 审批弹窗：完整路径 + 待写入内容（启用 laya/决策提示插件时另有风险与建议，仅供参考） |
| 3 | 打开右侧「审计」页 | 每轮 LLM I/O、工具调用、脱敏/还原逐条留痕；链条完整性「有效」 |
| 4 | 打开右侧「工作流」页签，启动「周报生成」 | 步骤状态 → **逐个**点「通过」（有 2 个强制审批步：生成草稿、人工审核）→ 导出执行记录 |
| 5 | 设置 → 插件，启用「自定义敏感词表」并加一个词，然后在输入框输入含该词的一句话（不必等回复） | 绿色判定条显示该词被替换为 `[PLUGIN_…]`；启停写审计 |
| 6 | 打开控制端 `Yindun-Control-v3.6.21.exe` | 态势/台账/资产/策略/用量/统计；策略只能收紧；三角色 RBAC |

> 提示：演示中转站有频率限制（20 次/分钟/IP）；若出现「上游限流」，等待约 10 秒再试。

## 四、评测复现

```bash
python tests/privacy_holdout_eval.py   # 留出集：60 篇 / 296 注入 / 80 负样本
python tests/privacy_eval.py           # 开发集攻防：出网/误报/往返/劫持
python tests/privacy_docs_eval_test.py # 8 种真实格式全链路
python tests/test_chat_adapters.py     # 四种接口格式协议一致性
```

评测结果：**在册 281/281、已声明不可合理识别 0/15（5 类）、全量 281/296（94.9%）、负样本 0/80**。
另外两条与覆盖率无关的架构性质：已识别实体出网明文 **0**、还原劫持 **0/500**、往返 **60/60**。

## 五、能力边界（如实声明）

- 不主张"召回 100%"：识别覆盖率是**依赖语料的经验测量**，未覆盖形态与原因公开在技术报告 5.4；
- 不保证对"未被规则覆盖的实体类型"或"可由背景知识重识别的属性组合"提供保护；
- 执行沙箱是**策略层 + 进程容器**，不是 OS 级隔离；
- 控制面仍缺**多租户隔离与证书轮换**，多组织共用前必须补齐；
- 演示中转站仅供评审试用，有额度与频率限制，不承诺 SLA。
