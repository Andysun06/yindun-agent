隐盾安全智能体

面向数据隐私安全的 AI 协同办公桌面智能体 · V3.6.21

一

作品简介

约 280 字

“隐盾”是一款面向数据隐私安全的 AI 协同办公桌面智能体。它以无边框 Web 桌面窗口运行（可一键置顶），支持本机 / 局域网 / 公网三档算力，在提供文档解析、项目分析、文件管理等协同能力的同时，将数据安全置于首位。系统内置内存级隐私脱敏网关，可识别手机号、身份证、银行卡、API 密钥等 30 类敏感实体，在内存中就地脱敏、汇报时安全还原；内置全链路审计黑匣子，以 HMAC 哈希链与外部锚点记录每次工具调用与数据流转，删改可被检出；通过文件沙箱、四档权限与人工审批约束物理副作用。其目标是让 AI 在安全可控、隐私合规的前提下深度融入日常办公。

二

主要功能与预期目的

约 300 字

主要功能包括：内存级隐私脱敏，识别并匿名化 30 类敏感实体，杜绝真实隐私落盘，并支持跨轮次可靠还原；权限分级与熔断拦截，提供计划模式 / 变更前确认 / 自主模式 / 完全访问四档权限（只决定要不要人工确认，不决定底线——执行命令在任何档位都需人工确认，系统目录与凭据路径的拦截与档位无关）；全链路审计黑匣子，哈希链加外部锚点，篡改与尾部截断可被即时发现；本地知识库与脱敏 RAG，文档入库即脱敏，向量库只存占位符；ReAct 智能推理与协同工作流，支撑离线文档解析、项目分析、文件管理与步骤级人工审批；插件体系只做加法，脱敏豁免、白名单、审批放行、审计写入等判定权永不开放。预期目的是在隐私安全与办公效率之间取得平衡，使敏感数据“可用不可见”。

三

设计方案及技术实现

约 290 字

系统采用分层架构：界面层基于 Web（pywebview + WebView2，原生 ES + 设计 token，无构建步骤）构建；核心层封装隐私脱敏、权限策略、审计日志、知识库、工作流与记忆管理等模块；后台层运行基于 LangChain 原生 Tool Calling 的 ReAct 推理循环。隐私引擎通过正则粗筛与程序化精验发现实体，映射表以 Fernet 加密并加入随机 nonce 防止还原劫持；审计日志以 HMAC-SHA256 链式校验防篡改，链头由外部锚点保护；知识库采用 Chroma 与本地 Ollama 嵌入，全程无云端依赖；文件工具经 realpath 沙箱校验与策略管理器 fail-closed 审批，命令走白名单与 Job Object 进程容器；模型接入支持 OpenAI 兼容、Anthropic Messages、OpenAI Responses 与 Ollama 原生四种接口格式。

四

创新及应用前景

约 280 字

创新之处在于：首创“内存级脱敏网关”模式，敏感数据全程以密文与占位符流转，实现脱敏—还原闭环；“入库即脱敏”的 RAG 管线从源头杜绝隐私落盘；哈希链审计黑匣子加外部锚点，把 AI 操作全流程置于可追溯的监督之下；插件体系“判定权不外放”，安全能力只能收紧不能放松；评测采用留出集与公开未覆盖清单（在册 281/281、全量 281/296、负样本 0/80），以可验证的诚实替代“零泄露”口号。应用前景广阔，可服务于政企办公、金融、医疗、法律等数据合规要求高的行业，也可作为个人本地 AI 助手的隐私加固方案；契合数据安全法规趋严的行业趋势，具备较强的推广价值与市场潜力。
