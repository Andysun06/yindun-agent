# 隐盾安全智能体 · 现场演示预案（V3.6.20，2026-10-24 更新）

> 给答辩/路演用：**四段演示的讲法与降级路径**。每段都写清"正常怎么讲"与"万一出问题改看什么"。
> 三个现场风险（算力没起 / laya 首次预热 / 小模型偶发空回复）都已在代码里做了如实反馈，
> 本文把它们写成**可照着念的话术**。

## 0. 开场前 5 分钟检查清单

```bash
# ① 算力：确认本机 Ollama 在跑、模型在
ollama list                       # 期望看到 qwen3.5:4b（或演示用模型）
# ② 客户端：双击 dist/隐盾安全智能体_<版本>_便携版.exe
#    看到底部进度走完三段（探测算力 → 载入模型 → 已就绪）＝ 可开始
# ③ 控制端：双击 dist/隐盾控制端_<版本>_便携版.exe（自动开窗口并登录）
# ④ 备用：源码方式启动（exe 被杀软拦时的替代路径）
python run.py
```

三个**必看一眼**的状态位：

| 看哪里 | 正常 | 不正常时 |
|---|---|---|
| 客户端底部启动进度 | 「已就绪：qwen3.5:4b」 | 会写明"连不上本机算力（地址）…请确认 Ollama 已启动"——按提示做，然后点「重新检测」 |
| 顶栏「快速 / 思考」 | 演示脱敏与问答用**快速**（实测 40~90 秒 → 数秒） | 复杂判断才切「思考」，并预告"这条会慢一点" |
| 控制台左侧 | 「隐盾控制台 V<版本>」 | 版本徽标与 exe 名一致；不一致说明拿错了包 |

## 1. 四段演示（每段 1.5~2 分钟）

### 第 1 段：数据不出网（脱敏 → 还原）

- 讲法：「这条合同里有人名、手机、身份证、卡号。它们**在进模型之前**就被替换成加密占位符——
  模型全程只看得到占位符，回答返回时再在本机还原。」
- 动作：贴一段含 `甲方（采购方）：欧阳明`「联系人电话 138.1234.5678」的文本 → 发送 → 点开
  **审计黑匣子**，指出"模型输入"一栏里是占位符，而界面回答是还原后的真值。
- 可加一句（V3.6.2 新能力）："分隔符变体、复姓、表格里的姓名、汉字大写金额都能识别"。
- **万一出问题**：模型回答慢/为空 → 直接看审计面板（脱敏与还原在本地完成，不依赖模型），
  「脱敏这一层的数据是可以离线证明的」；随后点「重发」一次。

### 第 2 段：AI 权限四档（计划 / 变更前确认 / 自主 / 完全访问）

- 讲法：「权限分四档：**范围内的文件操作**按档位走；**可读写范围之外**的操作也按档位判定
  （计划拒绝 / 变更前确认逐次弹窗 / 自主与完全访问放行），**并且每一次范围外操作都进审计**；
  执行命令在任何档位都要确认。**可读写范围在哪、就在设置里改**——演示前先指到桌面/资料目录最省事。」
- 动作：设置 → 隐私与权限 → 依次点四档，指出下方**能力对照矩阵**会跟着变；
  再到顶栏点「本对话权限」胶囊 → 单独给本对话设一档（说明"新对话默认 + 每对话可覆盖"）。
- **万一出问题**：矩阵没刷新 → 点一次「返回」再进设置页（视图切换问题，非权限失效）；
  判定口径始终以内核为准（设置页底部写着这句话）。

### 第 2.5 段：桌面文件操作（最容易讲的一段）

**（V3.6.8 起桌面已在默认可读写范围内，不必再改设置）** 默认可读写范围 = 程序目录 + **桌面 / 文档 / 下载**，
所以"数一下桌面有几个文件""在桌面建个 txt""把桌面上的图片批量改后缀"开箱就能做。
若要把范围收到某个资料目录，再去：设置 → 隐私与权限 → **可读写范围** → 「选择目录…」；
顶部态势条的「沙箱」会立刻变成那个路径——这一步本身就是"边界可见、可配"的好素材
（★ 显式选了目录就**只认它**，桌面会重新变成"范围外"，演示前想清楚要哪一种）。

- 动作 A（读）：「我的桌面上有几个文件？」→ 助手真的去列目录并回答数量（不再回一句"超出安全沙箱"）。
- 动作 B（写）：「在桌面创建一个 `演示_隐盾.txt`，写一句今天日期」→ **会弹出审批**（变更前确认档），
  弹窗里显示**完整真实路径**与即将写入的内容 → 点「允许」→ 桌面上真的出现这个文件。
- 动作 C（文件管理，本轮新增的能力面）：「把桌面上所有 `.jpeg` 改成 `.jpg`」
  （或「把这几张图挪到 `桌面\素材` 目录」）→ 会先列目录、再逐个改/移动，结果里逐条列出 `旧名 → 新名`。
  讲法：「这类活以前它做不了——工具集里根本没有移动/改名能力；现在有了，而且**目标已存在时默认拒绝覆盖**、
  **批量改名遇到重名会整批拒绝**（不会改一半）。要做到这一步，得先有工具，再谈权限与边界。」
- 讲法：「刚才那个弹窗就是熔断审批：路径、内容都摆在面前让你核；这次操作同时写进了审计链。
  换成自主/完全访问档就是不再逐次问，但**范围之外**的操作依旧会额外留痕——**放行不等于不留痕**。」
- **万一出问题**：① 助手说"读不到/被拒绝" → 先看态势条的沙箱路径（多半是设置没生效或指错了目录）；
  ② 计划模式下写入会被直接拒绝（这是设计，不是故障）→ 演示前把档位切到「变更前确认」。

### 第 3 段：laya 三级接入（本机 / 局域网 / 正则）

- 讲法：「laya 只做一件事：在审批弹窗里补一行风险分级，**不参与放行判定**。
  三级来源按数据边界分：本机模型（不出本机）→ 局域网服务（出机器、不出企业）→ 本机正则规则。」
- 动作：插件页启用「laya 风险分级」→ 设置栏会出现它的专属设置页 → 点「本机」看探测结果，
  切「局域网」看一眼端点/模型字段（**不用真连**，讲清"没连上就自动回退正则"），切「正则」看规则文件。
- **万一出问题**：首次启用要后台预热（实测 30~50 秒）。若此时触发审批，提示里会写明来源是
  **「本机正则规则」**——这句可以直接念："现在这条走的是确定性正则规则，模型还在预热。"
  预热完成后（设置页显示「本机 laya 模型」）再触发一次即可。

### 第 4 段：控制面（企业侧集中管理）

- 讲法：「控制面**架构上拿不到明文**——它看到的等于端点本地审计落盘的内容（已掩码）；
  策略**只能收紧**：可下发的是敏感路径并集、审批下限取更严、允许模型/插件取交集、强制严格模式。」
- 动作：控制台 → 态势总览 →（可选）事件台账/端点资产 → 策略下发选一条敏感路径 →
  回到客户端看那条路径的只读操作变成"需审批"。
- 可加一句（V3.6.2 新能力）：「现在的控制面支持只读账号（巡检只读、不能下发）、
  启动即备份、端点失联 Webhook 告警、策略回滚——回滚只改推荐，端点侧只收紧不会放宽。」
- **万一出问题**：回环演示用"配对码接入"最快；令牌见 `control_data/admin_token.txt`。
  浏览器打不开 → 用 `python -m yindun.control --browser` 或看终端打印的地址。

## 2. 三个现场风险的降级路径（都有代码级兜底）

| 风险 | 现场表现 | 代码里已做的兜底 | 你该说什么/做什么 |
|---|---|---|---|
| **Ollama 未起 / 模型缺失** | 底部进度停在"载入模型"，或提示未就绪 | `llm_status().error` 会写明**哪一步**不可用：连不上端点 / 没选模型 / 本机没这个模型，并给出 `ollama serve`、`ollama pull` 这类可执行建议（V3.6.2 补） | 跟读提示照做；若来不及，先演示第 1 段的**审计与脱敏**（不依赖模型） |
| **laya 首次预热 30~50 秒** | 启用后第一次审批的提示来源是「本机正则规则」 | 启用即后台预热；预热完成前**回退正则**并如实标注来源（不冒充模型） | 念："这条走确定性正则规则"；过几秒再触发一次即可看到模型来源 |
| **小模型偶发空回复（实测约 1/5）** | 回答只有一句"模型未给出有效回答…" | 按场景分支的兜底话术（无附件不再谈 PDF/OCR），并给出建议 | 念兜底那句话本身就是"如实"，然后点「重发」；或切「思考」模式再试 |

## 3. 演练验收（答辩前照此连做 3 次）

1. 冷启动：双击 exe → 底部三段进度走完 → 发送第 1 段文本 → 审计面板能看到占位符。
2. 权限四档切一遍 → 顶栏胶囊单独设一档 → 关掉应用重开，设置仍在（设置即时生效且持久）。
3. 插件页启用 laya → 等预热完成 → 触发一次审批看到「本机 laya 模型」来源。
4. 控制端：配对码接入 → 下发一条策略 → 客户端命中"需审批"。
5. **每段都问自己一句**："如果这里出问题，我改看什么？"——答不上来就补进上表。

> 相关：现场排障看 `logs/yindun.log`（exe 同目录，含启动/模型载入/插件与工具调用/异常栈；
> 需要更细的内部输出时加 `--log-capture-prints` 启动）。命令速查见开发记忆 §9。
