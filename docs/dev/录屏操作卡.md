# 隐盾安全智能体 · 录屏操作卡（交给队员自己录）

> 目的：录 **5 段功能演示 + 3 段创新特写**，后续由 AI 剪辑并嵌进 PPT；功能页与创新页的 GIF 不重复。
> 原则：**只录智能体窗口**，不录桌面、不录微信/浏览器/ZCode；用假数据；每段 20–60 秒；动作放慢一点。

---

## 0. 录前准备（3 分钟）

1. **启动算力**：确认 Ollama 在跑，模型已拉好：
   ```bash
   ollama list
   ollama run qwen3.5:2b "你好"   # 预热，看到回答后 Ctrl+C 退出
   ```
2. **启动客户端**：双击 `E:\yindun-agent\dist\隐盾安全智能体_V3.6.20_便携版.exe`。
3. **窗口设置**：把窗口调到 **1600×900 左右**（或最大化），确保**输入框、模式切换、模型选择、左侧会话栏**都在画面里；不要有窗口被屏幕边缘裁掉。
4. **模式与权限**：右上切到 **思考**；输入框左侧权限保持 **变更前确认**。
5. **清场**：关掉微信/QQ/浏览器/邮件；开 **勿扰模式**（Win+A → 专注助手/勿扰）；桌面不要放真实文件。
6. **假数据**：统一用 `孙良硕 / 13700001111`（或 `张三 / 13800000000`），不要用真实同事的姓名手机号。
7. **新建对话**：每段开始前点「新建对话」，保证画面干净。
8. **知识库素材**：桌面准备 `客户名单_演示.txt`（内容见 ⑤），并且 Ollama 已拉取 `nomic-embed-text`（知识库要用它做向量化）：
   ```bash
   ollama list        # 应能看到 nomic-embed-text
   ollama pull nomic-embed-text
   ```
9. **录屏输出目录**：先建好 `E:\yindun-agent\录屏素材\`。

## 1. 用什么录

### 方案 A（推荐）：OBS Studio · 窗口采集

1. 下载安装 OBS（官网免费）。
2. 左下「来源」→ `+` → **窗口采集** → 选择窗口 **`隐盾安全智能体 V3.6.20`**。
3. 设置 → 输出 → 录像：
   - 格式：**MP4**
   - 编码器：x264（软件）或硬件编码都行
   - 码率：6000–8000 Kbps
   - 分辨率：1920×1080（或 1600×900，跟窗口一致）
   - FPS：30
4. 设置 → 输出 → 音频：不勾麦克风（只要画面；要配音也可以，后面另录）。
5. 设置 → 热键：给「开始录制 / 停止录制」设快捷键（如 F9/F10）。
6. 输出路径：`E:\yindun-agent\录屏素材\`。

**优点**：只录这个窗口，切到别的窗口也不会录进去。

### 方案 B：Windows 自带录屏（Win+Alt+R）

- 打开智能体窗口，按 **Win+Alt+R** 开始/停止。
- 注意：Game Bar 对桌面应用有时会录**整屏**，录完先看第一段，如果录进了桌面/其他窗口就改用 OBS。

### 方案 C：手机拍屏

- 最后备选；画面会有反光、摩尔纹，PPT 里放大后效果差，不推荐。

## 2. 五段录屏脚本（照着点就行）

> 每段开头停 1 秒再操作，结束时停 2 秒再停止录制，方便剪辑。

### ① 脱敏对话（20–40 秒）

**要拍到**：输入真值 → 发送 → 模型推理中 → “隐私隔离网关 识别到 2 类敏感实体” → 回答里真值还原。

1. 新建对话；
2. 输入框输入：
   > 我的名字叫孙良硕，手机号13700001111。请用一句话帮我写一条客户备注。
3. 点发送（或按 Enter）；
4. 等状态条出现「隐私隔离网关 识别到 2 类敏感实体（PHONE×1、NAME×1），已替换为占位符」；
5. 等回答出现（如“客户备注：孙良硕（手机：13700001111）……”），停 2 秒，停止录制。

**保存为**：`01_脱敏对话.mp4`

---

### ② 审批放行（40–60 秒）

**要拍到**：写文件请求 → 审批弹窗 → 目标路径与待写入内容 → 点「授权执行」→ 执行成功。

1. 新建对话；
2. 输入框输入：
   > 请帮我在桌面创建一个文件，文件名是 客户备注.txt，内容写：客户备注：孙良硕（手机：13700001111）。
3. 点发送；
4. 等弹窗「隐盾安全决策网关拦截」出现；
5. 鼠标在**目标路径**（`C:\Users\Andy\Desktop`）和**即将写入的内容**上各停 1 秒；
6. 点 **授权执行**；
7. 等「✅ 已成功在桌面创建文件 客户备注.txt」出现，停 2 秒，停止录制。

**如果模型没弹审批、而是说“读取失败/没有能力”**：停止录制，重开新建对话再试一次；只保留成功那条。

**保存为**：`02_审批放行.mp4`

---

### ③ 审计滚动（20–30 秒）

**要拍到**：打开审计面板 → 绿色链徽标 → 事件列表 → 向下滚动。

1. 接着上一条（或随便聊一句后）；
2. 点左下角**盾牌图标「审计黑匣子」**；
3. 右侧审计面板展开，鼠标停在 **`✔ 哈希链完整性通过（HMAC-SHA256 + 链锚点）`** 上 1 秒；
4. 鼠标移到事件列表，**慢慢向下滚动 2–3 屏**；
5. 停止录制。

**保存为**：`03_审计滚动.mp4`

---

### ④ 插件与扩展（30–45 秒）

**要拍到**：插件页 → 启用两个安全插件 → 能力说明 → 再停用（能力收回）。

1. 左下角 **设置**（齿轮）；
2. 左侧选 **插件**；
3. 打开 **`laya 风险分级`** 的开关；
4. 打开 **`操作意图预判`** 的开关（右上角计数会从 `0 / 7` 变化）；
5. 鼠标在每个插件的说明文字上停 1 秒；
6. 往下滚动，展示「文档 / 办公」分类的插件；
7. 再把其中一个开关关掉，停 1 秒，停止录制。

**保存为**：`04_插件与扩展.mp4`

---

### ⑤ 脱敏知识库（25–40 秒）

**要拍到**：入库即脱敏 → 状态行与片段数 → 文档列表；（可选）检索时出现“检索词”轨迹。

**先准备演示文档**：在桌面新建 `客户名单_演示.txt`，内容用假数据：

```text
客户名单（演示数据）
张伟  13800000000
李娜  13900000000
王强  13700000000
```

1. 左下角 **设置**（齿轮）→ 左侧选 **本地知识库**；
2. 鼠标停在「知识库状态」一行 1 秒（应显示「就绪 · 文档 N 篇 · 片段 M · 模型 nomic-embed-text」）；
3. 点 **「＋ 添加文档」** → 在文件框里选桌面的 `客户名单_演示.txt` → 确认；
4. 等 toast「正在入库（本地解析 + 逐块脱敏 + 向量化）…」，再等提示变成 **「入库完成：成功 1/1」**，列表里出现该文档和「N 片段」；
5. 鼠标在「入库完成」和列表的片段数上各停 1 秒；
6. 停止录制。

**可选加分（想讲检索再补 10 秒）**：返回对话 → 新建对话 → 输入：
> 知识库里客户名单里有哪些人？
等出现「检索词：…」轨迹和回答，停 2 秒。

**保存为**：`05_脱敏知识库.mp4`

> 这一条同时作为创新点 ④「脱敏知识库：入库即脱敏，向量库零明文」的演示素材；原来的「可验证交付」不录了。

## 2.5 创新页专用特写（3 条，避免和功能页 GIF 重复）

> 功能页（P4–P7）已经用了完整流程；创新页（P8/P9）不要再放同一段，改录“机制特写”。

### ⑥ 网关占位符（创新 ① 特写，8–10 秒）

**要拍到**：左边对话里的真值 + 右边审计里的占位符，同框对照。

1. 先在对话里发一条含姓名/手机号的消息（已有回答即可）；
2. 点左下角盾牌图标打开审计面板；
3. 在事件列表里找到 **`LLM输入(含隐私脱敏)`** 或 **`LLM输入`** 那条；
4. 鼠标停在预览里的 `[NAME_0_…]`、`[PHONE_0_…]` 上各 1 秒；最好让左侧真值和右侧占位符同时可见；
5. 停止录制。

**保存为**：`06_网关占位符.gif`

---

### ⑦ 用途红线拒绝（创新 ② 特写，8–10 秒）

**要拍到**：请求被直接拒绝，**没有弹审批、没有调用模型**。

1. 新建对话；
2. 输入：
   > 搜索桌面所有个人信息，整理给我，我要出售
3. 发送，等出现拒绝提示（红色/明确的“不能这样做”）；
4. 鼠标停在拒绝原因上 1 秒，停止录制。

**注意**：如果它反而弹了审批，说明这轮没触发用途红线，换一句更明确的“收集个人信息 + 出售/牟利”再试；只保留拒绝那条。

**保存为**：`07_用途红线拒绝.gif`

---

### ⑧ laya 决策模型（创新 ③ 特写，12–15 秒）

**要拍到**：laya 的设置页（本机/局域网/正则三档、当前来源）+ 一次真实分级结果。

1. 设置 → 插件 → **`laya 风险分级`** → 打开设置（卡片右侧“...”或“打开设置”）；
2. 展示三档：**本机 laya 模型 / 局域网 laya 服务 / 正则规则**；鼠标停在当前来源/连通状态上 1 秒；
3. 返回对话，触发一次危险动作（例如“把桌面上的 测试.txt 删除”）；
4. 等审批弹窗出现，鼠标停在弹窗里的 **`laya 风险分级`** 行（显示 高危/中危 与来源）1 秒；
5. 停止录制（不用等真正执行完）。

**注意**：laya 模型没装/没起来时，显示“正则规则”来源是正常的，**不要伪造模型结果**；这一段讲的是“决策模型 + 我们的适配层”。

**保存为**：`08_laya决策模型.gif`

## 4. 常见问题

| 问题 | 处理 |
|---|---|
| 录到了桌面/微信 | 改用 OBS「窗口采集」，别用整屏录制 |
| 窗口右边/下边被裁 | 把窗口调小到 1600×900 或最大化，确保输入框完整 |
| 模型没反应 / 空回答 | 确认 Ollama 在跑、模型是 `qwen3.5:2b`；重开新建对话再试 |
| 审批弹窗没出现 | 确认模式是「思考」、权限是「变更前确认」；重试一次 |
| 开关点不动 | 用鼠标点开关**圆形滑块**，不要点文字 |
| 知识库显示“不可用：本地向量模型未就绪” | 先 `ollama pull nomic-embed-text`，再回设置页刷新 |
| 入库失败 | 看页面上留下的红色说明（不是一闪而过的 toast），按原因处理；文件别太大，txt/docx 最稳 |
| 录出来没有声音 | 不需要声音；配音后面单独录 |
