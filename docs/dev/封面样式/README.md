## 六种风格

| 编号 | 名称 | 气质 | 适合场景 | 风险 |
|---|---|---|---|---|
| 01 | 深色发布会 | 黑底 + 荧光绿 + 盾形线稿 | 主推。投影仪效果好，最像产品发布会 | 暗色在强光教室可能发灰 |
| 02 | 科技蓝 | 深海军蓝 + 青色节点网络 | 强调“安全 / AI / 数据流” | 网络线稿略复杂，远看偏暗 |
| 03 | 杂志编辑 | 米白纸感 + 衬线大字 + 墨绿侧栏 | 有设计感、偏答辩/评审 | 衬线字在低分屏上略细 |
| 04 | 大创赛海报 | 酸黄 + 黑 + 橙红条 | 最“冲”，大创赛/路演气场 | 高饱和，投影差时刺眼；评委偏保守慎用 |
| 05 | 克制学术 | 白底 + 深绿 + 大留白 | 评委偏学术、重严谨 | 远看偏“素”，不够发布会 |
| 06 | 红金正式 | 深红 + 香槟金 + 印章 | 校企合作、企业/政府评委 | 容易显得“传统”，不够科技 |

## 建议

- **首选 01**：5 分钟答辩 + 视频演示，深色封面和演示视频的黑底界面最连贯。
- **备选 03**：如果预答辩教室很亮、投影偏灰，米白底更稳，且“隐盾”两个衬线大字很有记忆点。
- **企业评委多** → 06；**学术评委多** → 05；**想要大创赛气场** → 04；**主打安全科技** → 02。

## 使用约定

1. 选定后，**正文页不要六种风格混用**：从封面取 2 个主色 + 1 个强调色，正文沿用同一套。
2. 建议“深色封面 + 浅色正文”混合：封面用 01/02，正文用白底深绿/深蓝文字，投影更清楚。
3. 字体只用两种：中文 `Microsoft YaHei`（正文）/ `Noto Serif SC`（大标题），英文/数字 `Bahnschrift` 或 `Consolas`。
4. 标题不小于 40pt，正文不小于 18pt；一页只留一个结论。
5. 封面上的 `V3.6.17`、`庆园杯`、`2026` 可按实际赛道名替换，位置不要移动。
