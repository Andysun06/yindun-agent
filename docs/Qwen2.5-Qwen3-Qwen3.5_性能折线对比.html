Qwen2.5 → Qwen3（→ Qwen3.5）各参数量能力对比

数据来源：Qwen3 技术报告（arXiv:2505.09388）后训练评测表；横轴 = 参数量（B，对数刻度）。 MMLU-Pro 为基座模型对比（该报告未发布 Instruct 版全尺寸数字）。 Qwen3.5 各尺寸官方基准截至 2026-10 未公开检索到，故不出数据点，仅以蓝色竖带标注其尺寸区间 （Ollama 官方标注：tools ✅ / thinking / vision / 256K 上下文；中文 201 语言；397B 级 C-Eval 93.0）。

给隐盾演示环境的结论

  • 同尺寸全面代差：Qwen3 每一条线在每个参数量上都高于 Qwen2.5 对应点；4B 即追平/反超 Qwen2.5-7B ——BFCL 工具调用：Qwen3-4B（不思考）57.6 > Qwen2.5-7B 55.8，（思考）65.9 ≈ Qwen2.5-32B 62.8； IFEval 指令遵循：Qwen3-4B 81.2 ≈ Qwen2.5-14B 81.0。
  • 对隐盾最关键的两条：BFCL 决定 ReAct+工具调用链的稳定性，IFEval 决定"占位符/格式不被破坏"。 小模型这两项 Qwen3 提升最大（0.6B 的 IFEval 59.2 已超 Qwen2.5-1.5B 的 42.5）。
  • 思考模式是免费的性能档：同一权重开思考普遍 +3~15 分（蓝色虚线），代价是响应慢—— 演示抢时间用不思考档，复杂审计/工作流用思考档（项目 thinking_depth 若透传 think 参数可一键切换）。
  • 选型建议：演示机首选 qwen3.5:4b（3.3–4GB，新一代 + tools + 256K，官方逐尺寸分未公布，按代际规律预期 ≥ Qwen3-4B）； 保守可验证选择 qwen3:4b（2.5GB，数字见上图）；性能充裕 qwen3.5:9b / qwen3:8b。 现装的 qwen2.5:7b-instruct 体积更大、工具调用与指令遵循均落在 Qwen3-4B 之下。
