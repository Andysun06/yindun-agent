# 隐盾安全智能体 · 产品说明（示例）

隐盾是一款面向涉密办公场景的本地化隐私防护桌面智能体。

## 核心能力
- **内存级隐私脱敏网关**：可识别并脱敏 20 余类敏感实体，包括手机号、身份证号、银行卡号、邮箱、API 密钥、口令、病历号、医保卡号、金额、人名、地址、IP、MAC 等。
- **纵深执行防御**：文件路径沙箱、三级权限（完全控制 / 安全只读 / 彻底审计）、命令白名单（仅 python/pip/git/echo）、高危操作熔断人工审批。
- **全链路审计黑匣子**：HMAC-SHA256 哈希链防篡改，审计仅存脱敏预览。
- **脱敏 RAG 本地知识库**：文档入库即逐块脱敏，向量库中只存占位符，真实隐私永不落盘。

## 技术栈
Python、LangChain（原生 Tool Calling / ReAct）、PySide6 桌面端、Chroma 向量库、Ollama 本地算力，支持 OpenAI 兼容云端模型。

## 数据分级
敏感实体按 GB/T 35273 思想分为「绝密 / 机密 / 内部」三级，并给出加权风险评分。
