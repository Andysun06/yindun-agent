隐盾安全智能体 · 使用说明

面向涉密办公场景的本地化隐私防护桌面智能体 · V3.3 Yindun Security Agent — 让本地 AI 更安全、更智能、更可控

一、产品简介

隐盾安全智能体是一款常驻桌面的 AI 办公助手，核心差异在于内置内存级隐私防护： 所有敏感信息（手机号、身份证、银行卡、密钥、病历、金额、人名等）在进入大模型之前， 会在内存中自动替换为加密占位符；模型全程只见占位符，回答返回时再自动还原为明文呈现给你。

配合文件沙箱、权限分级、命令白名单、高危操作人工审批与哈希链审计， 隐盾把"数据出网、落盘、留痕"三大泄露面逐一关闭，让你放心把涉密文档交给 AI 处理。

典型用途：合同/简历/病历等涉密文档的问答与摘要、本地知识库检索、 项目代码分析、办公文件创建与整理、可追溯的操作审计。

二、安装与启动

方式 A：安装包（推荐）

  1. 双击 隐盾安全智能体_V3.3_安装包.exe；
  2. 按向导点击"下一步"（默认安装到当前用户目录，无需管理员权限）；
  3. 完成后勾选"立即启动"，或双击桌面"隐盾安全智能体"图标。

卸载：开始菜单 → 隐盾安全智能体 → 卸载，或经"控制面板 → 程序和功能"。

方式 B：源码运行

# Python 3.10+，安装依赖
pip install -r requirements.txt
python run.py

首次启动若被杀毒软件 / Windows Defender 提示，选择"仍要运行"或添加信任即可 （未签名的绿色软件常见误报，源码可自查）。

三、首次使用：配置一个"算力底座"

隐盾需要接入一个大模型作为算力底座，两种方式二选一（约 2 分钟）。 启动后若顶部状态栏显示"✅ 安全算力联通成功"即已就绪；否则点右上角 ⚙ 设置进行配置。

方式 A：本地离线模型（推荐，数据全程不出网）

  1. 下载安装 Ollama：https://ollama.com/download（安装后服务自动运行）；
  2. 打开命令行执行，拉取一个支持工具调用的模型： bash ollama pull qwen2.5:7b-instruct 如需使用知识库检索，再拉取向量模型： bash ollama pull nomic-embed-text
  3. 启动隐盾，在设置页"算力底座 → 模型选择"中选中检测到的本地模型。

方式 B：云端模型（无需下载大文件）

  1. 点右上角 ⚙ 设置 → 算力底座 → ➕ 新增外部；
  2. 填入任一 OpenAI 兼容 API 的参数（示例：智谱开放平台）： - base_url：https://open.bigmodel.cn/api/paas/v4 - api_key：你自己的密钥 - model_id：glm-4-flash
  3. 保存后在模型下拉框选择该模型。

隐私提示：开启"隐私隔离网关"（默认开启）时，发往云端的内容已自动替换为占位符， 真实敏感数据不出本地。

四、核心功能使用

4.1 对话与隐私脱敏

直接在底部输入框下达指令即可。含敏感信息的内容会先脱敏再交给模型，回答后自动还原。

  • 快速 / 思考模式：输入框上方切换。快速模式为只读安全模式（禁止一切写盘/删除/命令执行）； 思考模式支持完整工具调用与多轮推理（思考深度 1–10 在设置页调节）。
  • 挂载文件：点"📎 挂载文件"上传 PDF / Word / Excel / TXT 等，直接在对话中就其内容提问。
  • 会话管理：💬 切换历史会话，➕ 新建会话；多会话相互隔离，记录加密存储。

4.2 本地知识库（脱敏 RAG）

在设置页底部"本地知识库"区，点"➕ 添加文档"将机密文档入库（入库即逐块脱敏， 向量库中只存占位符，真实隐私永不落盘）。之后在对话中即可语义检索问答。

4.3 协同工作流

点顶部 🔀 进入工作流编排，内置合同审查 / 周报生成 / 代码安全检查等模板， 支持步骤编排、执行、审批通过与人工拦截。

4.4 审计黑匣子

点顶部 📊 查看全链路审计：LLM 输入输出、工具调用、脱敏还原、审批决策逐条留痕， 哈希链完整性状态实时可见，可一键导出 JSON / HTML 审计报告。

五、安全机制说明

机制 作用
隐私脱敏网关 20+ 类敏感实体识别，进模型前占位符化，映射表 Fernet 加密、密钥 DPAPI 保护
文件沙箱 所有文件操作限定在沙箱目录内，越界读写一律拒绝
权限分级 完全控制 / 安全只读 / 彻底审计 三档，按需收口写盘能力
命令白名单 仅放行 python/pip/git/echo，去 shell 化执行，杜绝命令注入
熔断审批 高危操作挂起后台线程，强制人工二次确认，超时自动驳回
哈希链审计 HMAC-SHA256 链式存储，篡改即告警；审计自身只存脱敏预览

六、数据与隐私

  • 配置：安装目录下 global_config.json（模型、权限、界面等）。
  • 会话：chat_sessions.json，内容加密存储。
  • 审计：audit_logs/，哈希链防篡改，仅存脱敏预览。
  • 知识库：data/knowledge_base/，只存占位符向量。
  • 卸载即清除以上全部本地数据。

七、常见问题（FAQ）

  • 状态栏显示"模型初始化失败"：未装 Ollama 或未拉取模型，按第三节方式 A 完成，或改用方式 B。
  • 杀毒软件报警：未签名绿色软件常见误报，添加信任即可。
  • 想让 AI 写文件却提示"快速模式无法执行"：切到"思考"模式再试。
  • 回答里出现 [PHONE_0_xxxx] 这类占位符没还原：属跨轮历史占位符，正常会随会话映射还原； 若长期不还原，可在设置页关闭再开启"隐私隔离网关"重置会话。
  • 换了电脑/重装系统后旧会话无法还原明文：脱敏密钥绑定 Windows 用户账户（DPAPI）， 属安全优先于可恢复性的既定设计。
