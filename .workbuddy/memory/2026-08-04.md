## 解析「隐盾安全智能体 Yindun Security Agent V3.2」Agent 应用
- 用户请求（scene#17）解析该 Agent 的目标与核心功能。
- 项目结构：入口 `run.py` → `yindun/main.py`（QApplication 点火）→ `yindun/gui/main_window.py`（GUI 骨架）；推理核心在 `yindun/worker/agent_worker.py`（Worker，ReAct + LangChain 原生 Tool Calling）；`yindun/core/` 含 file_tools / privacy_engine / memory_manager / policy_manager / audit_log / knowledge_base。
- Agent 目标：常驻桌面置顶的半透明本地 AI 助手；本地算力优先、面向文件/代码/文档生产力；安全可控（隐私脱敏 + 权限拦截）是第一约束。
- 核心功能：① ReAct 推理循环（快速3轮禁写 / 深度 depth×2 轮 + 最低轮数约束 + 0.5s 可取消 + 强制工具调用）；② PrivacyEngine 内存脱敏网关（16 类实体 + 轻量人名识别，Fernet 加密映射表用后即焚）；③ PolicyManager 三级拦截 approve/confirm/deny + 三级权限模式；④ 上下文记忆自动摘要压缩 + 多会话持久化；⑤ 离线文档解析 + 分块检索 + 脱敏知识库 RAG + LaTeX 渲染；⑥ 全程审计日志与数据看板。

## 用户总体目标 & 改进建议讨论
- 用户明确总目标：完成一个「面向数据隐私安全的 AI 协同办公桌面智能体」。
- 现有隐盾定位偏"单用户本地文件助手"，距"协同办公"仍有 gap。
- 给出的优先级改进建议（P0 安全底线 / P1 协同 / P2 架构）：
  - P0：① PolicyManager 当前"无规则匹配默认 approve"须改为默认 deny + 显式 allowlist；② 脱敏盲区（统一社会信用代码/车牌/生物特征/自定义字段）+ 映射表单点风险，建议混合 NER + 不可逆哈希脱敏 + 密钥进 Keychain/TPM；③ 缺 Prompt Injection 防护（外部文档内容隔离标注，工具调用不受注入驱动）。
  - P1：单用户→多用户身份、RBAC、共享会话/知识库权限边界、E2E 加密协同；共享知识库隐私策略继承。
  - P2：MCP 工具市场（过隐私网关）、多 Agent 编排、模型路由（本地/云端）、沙箱隔离执行（run_local_command 当前直跑 subprocess）、审计哈希链 + 输出水印、合规对齐（GB/T 35273 / 个保法 / 等保 2.0）。
- 已用 Visualizer 画"隐私优先目标架构"（协同办公层 / 智能体能力层 / 隐私安全底座三层）收口。
