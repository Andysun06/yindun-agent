# 🛡️ 隐盾安全智能体（Yindun Security Agent）· V3.6.21

> **让大模型"看不见"敏感数据，却依然能完成办公任务。**
> 数据进入模型前在内存中替换为加密占位符，模型全程只见占位符，回答返回时自动还原；
> 配合文件沙箱、命令白名单、熔断审批与 HMAC 哈希链审计，构成「输入—推理—执行—落盘—审计」全链路纵深防御。

| 识别能力 | 留出集实测 | 架构承诺 | 权限 | 扩展 | 交付 |
|---|---|---|---|---|---|
| 30 类敏感实体 | 281/296（94.9%） | 已识别实体出网明文 **0** | 四档 + 硬底线 | 7 个内置插件 | 客户端 + 企业控制端 |

---

## 这是什么

大模型进入办公场景有一个根本矛盾：**数据越敏感，越需要模型的能力，也越不能让它跨出本机。**
隐盾的做法是把"安全"从使用约定下沉为架构约束：

- **模型侧拿不到明文**：内存级脱敏网关先把敏感值换成 `[PHONE_0_x]` 形式的占位符，映射表用 Fernet 加密、密钥由 Windows DPAPI 保护；模型看到、收到的都是占位符。
- **物理副作用受控**：文件操作限定在「默认可读写范围」内（程序目录 + 桌面/文档/下载），越界按权限档位判定并写审计；命令走白名单 + 子命令级校验 + Job Object 进程容器；高危操作一律人工审批，审批卡展示完整路径/命令/待写入内容，杜绝盲签。
- **事后可追责且自身不泄露**：HMAC-SHA256 哈希链 + 外部锚点，六类删改手法可检出；审计只落脱敏预览，导出同样过掩码。

## 核心能力

### 1. 隐私脱敏网关（`core/privacy_engine.py`）

- **30 类实体**：手机号 / 固话 / 邮箱（含 `(at)` 混淆写法）/ 身份证（15/18 位）/ 银行卡（含非 Luhn 卡面数字）/ IP / IPv6 / MAC / 金额 / API 密钥 / JWT / 私钥 PEM / 云平台密钥 / 连接串口令 / 口令字段 / 护照 / 车牌 / 统一社会信用代码 / 病历号 / 医保号 / 微信号 / 地址 / 敏感路径 / 人名等。
- **两段式识别**：正则粗筛 + 程序化精验（Luhn、手机号位数、身份证地区码与校验位、人名上下文窗口），按精确命中区间替换，避免"同一子串先在非敏感位置出现"导致的明文残留。
- **跨轮还原**：映射表跨会话持久化；摘要二次脱敏；未还原的占位符不会原样甩给用户（展示兜底）。
- **三级数据分级**（参照 GB/T 35273）：绝密 / 机密 / 内部，用于风险量化与审计展示。

### 2. 权限四档与沙箱（`core/permission.py`）

| 档位 | 读 | 写盘 / 删除 / 移动 | 执行命令 |
|---|---|---|---|
| 计划模式 | 放行 | 拒绝 | 拒绝 |
| 变更前确认（默认） | 放行 | 逐次弹审批 | 弹审批 |
| 自主模式 | 放行 | 自动执行 | 弹审批 |
| 完全访问 | 放行 | 自动执行 | 弹审批 |

- 档位定义**只有一处**，工具层、审批流、界面矩阵全部由它派生；切换后下一个操作即生效，无需重启。
- **硬底线不随档位放开**：执行命令在任何档位都要人工确认；系统目录 deny、凭据路径 confirm、脱敏网关、审计链一律照旧。
- 可读写范围是「默认范围」而不是绝对墙：范围外操作按档位判定、每次写审计、工具结果明写真实路径——不做静默放行。

### 3. 审计黑匣子（`core/audit_log.py`）

- 每轮记录工具调用、LLM I/O、脱敏/还原、审批决策；HMAC-SHA256 哈希链，中间删改、批内断链、尾部截断可检出。
- **外部锚点**：固定条数 + 链头 + legacy 前缀，放在密钥旁边（用户目录）而非审计目录内，堵住"抹掉标记重算整链"的降级改写。
- 面板实时刷新（2 秒）、支持按类型/严重程度筛选与搜索、导出 JSON/HTML；**导出内容同样过展示层掩码**。

### 4. 智能推理与文件能力（`worker/agent_worker.py`、`core/file_tools.py`）

- LangChain 原生 Tool Calling + ReAct 循环；快速模式 6 轮、深度模式按思考强度 2–20 轮。
- 取消约 0.3 秒返回；重复调用短路；失败反馈可行动化；工具结果真值校验（声称写入/删除后到文件系统核对）。
- **15 个工具**（见下表），覆盖列目录、读写、项目分析、检索、创建/修改/移动/复制/改名/批量改后缀/建目录/删除/受限命令。
- 删除指令**在任何模型调用之前**识别"删除 + 完整路径 + 文件存在"，直接走审批；答复由宿主确定性生成，不给模型编造机会。

### 5. 知识库与插件

- **本地知识库 + 脱敏 RAG**：Chroma + Ollama embedding；文档**先整篇脱敏再切块**，向量库只存占位符；检索结果标注"片段不是全文"，低相关时明确说"知识库里没有这条"。
- **插件体系：内核不可插件化，其余皆可插**。判定权（脱敏豁免 / 白名单 / 审批放行 / 审计写入）通过 `FORBIDDEN_HOOKS` **永久不开放**；增强型钩子只能做加法（补充识别、扩展解析、工作流模板、导出格式），返回值经内核净化，内核兜底始终在。
- **7 个内置插件**（默认关闭，按需启用，启停写审计）：自定义敏感词表 / 扩展附件解析（.eml/.html/.mht）/ 办公工作流模板包 / 导出格式扩展 / 审批决策提示 / 操作意图预判 / laya 风险分级（本机→局域网→正则三级接入）。
- **工作流**：右栏「工作流」页签，模板 → 启动 → 执行下一步 → 待审批 → 通过/驳回 → 导出执行记录；写盘/删除/执行/导出步骤由内核强制人工审批。线性流程，不提供分支/回退（如实声明）。

### 6. 界面与企业控制端

- Web 界面（pywebview + WebView2，原生 ES，无构建步骤）：三栏工作台、可拖宽、窄屏自动收起、极简闪发浮条（420×60，输入回车自动展开发送）、置顶即时生效、明暗双主题、Markdown 富文本。
- **企业控制端**（`yindun/control/`，零新增依赖）：集中控制台（态势 / 台账 / 资产 / 策略 / 用量 / 统计），**策略只能收紧**（降级键整包拒绝）、审计链外部锚定、配对码纳管、端点上报默认关闭且本机留痕。
- 控制面 V3.6.21 起：**三角色 RBAC**（admin / operator / viewer，命名令牌可吊销）、**速率限制默认开启**（600 次/分钟/IP）、**TLS 一键自签**（`--tls-auto`）。

## 安全边界与诚实声明

这一节比功能列表重要——它决定"能承诺什么、不能承诺什么"。

**明确不主张：**

- 不主张"召回 100%"或"零遗漏"：识别覆盖率是**依赖语料的经验测量**，评测脚本与未覆盖清单随仓库提供；
- 不保证对"未被规则覆盖的实体类型"或"可由背景知识重识别的属性组合"提供保护；
- 执行沙箱是**策略层 + 进程容器**，不是 OS 级隔离（放行的脚本仍以当前用户权限运行）；
- 控制面仍缺**多租户隔离与证书轮换**，多组织共用前必须补齐；
- 能重写整机的人超出防护目标（等价"用户本人"）。

**评测口径（可复现）：**

| 口径 | 结果 | 说明 |
|---|---|---|
| 在册形态 | **281 / 281** | 引擎声明支持的写法 |
| 已声明未覆盖 | **0 / 15（5 类）** | 不可合理识别的对抗形态（杂字符手机号、无分隔符固话、字符间空格姓名、双 `@` 邮箱、卡号夹字母）——刻意不追，公开列出 |
| 全量口径 | **281 / 296（94.9%）** | 不做口径挑选时的诚实读数 |
| 负样本误伤 | **0 / 80** | 订单号、日期、版本号等业务数字必须原样保留 |
| 网关机密性 | 出网明文 **0**；劫持 **0/500**；往返 **60/60** | 针对**已识别实体**的架构保证，与识别覆盖率无关 |

复现：`python tests/privacy_holdout_eval.py`（留出集，60 篇 / 296 个注入值 / 80 个负样本）、
`python tests/privacy_eval.py`（开发集攻防）、`python tests/privacy_docs_eval_test.py`（8 种真实格式）。

### 首次使用

1. 设置 → 模型接入，按数据边界选一档：**本机**（Ollama，数据不出本机）/ **局域网**（内网推理服务，数据不出企业）/ **公网**（OpenAI 兼容接口，送出前已在本机脱敏）。
2. 至少准备一个支持 Tool Calling 的模型（推荐 `qwen3.5:4b` 或 7B 以上；2B 小模型只适合轻任务）。
3. 启动后本机模型自动检测并列出，点一下即切换，无需重启。

## 技术架构

### ReAct 循环

```text
用户输入
  ↓
[用途合规检查] → 触线直接拒绝（不调模型、不开审批入口、写审计）
  ↓
[隐私脱敏] PrivacyEngine.anonymize() → 模型只见占位符
  ↓
[上下文] 摘要压缩 + 工具消息配平
  ↓
ReAct 循环（max_rounds = 思考强度 × 2）
  ① llm.invoke(messages)
  ② 有 tool_calls → 执行工具 → ToolMessage（审批 / 沙箱 / 白名单在此拦截）
  ③ 无 tool_calls → 达到最低轮数则总结，否则继续
  ★ 每 0.5 秒检查取消标志
  ↓
[隐私还原] deanonymize() → 用户看到真实值
  ↓
[持久化 + 审计] 完整工具链落库；审计只存脱敏预览
```

### 15 个工具

| 工具 | 功能 | 权限 |
|---|---|---|
| `list_local_files` | 列目录 | 读 |
| `read_local_file` | 读文件 | 读 |
| `analyze_project` | 递归分析项目结构与关键代码 | 读 |
| `search_in_files` | 文件内文本搜索 | 读 |
| `read_attachment_chunk` | 长附件分片检索 | 读 |
| `search_knowledge_base` | 知识库语义检索（脱敏 RAG） | 读 |
| `create_local_file` | 新建文件并写入 | 变更前确认及以上 |
| `modify_local_file` | 修改文件内容 | 同上 |
| `move_local_file` | 移动（批量/改名） | 同上；默认拒绝覆盖 |
| `copy_local_file` | 复制/备份 | 同上 |
| `rename_local_file` | 就地改名（只收纯文件名） | 同上 |
| `batch_rename_local_files` | 批量改后缀（撞车整批拒绝） | 同上 |
| `make_local_dir` | 建目录（可多级） | 同上 |
| `delete_local_file` | 删除文件 | 按档位判定；越界额外写审计 |
| `run_local_command` | 受限命令（白名单 + 子命令校验 + Job Object） | **任何档位都需人工确认** |

## 依赖与配置

主要依赖：`langchain-ollama` / `langchain-openai` / `langchain-core`（推理与 Tool Calling）、
`chromadb` + `langchain-chroma`（本地向量库）、`PyPDF2` / `PyMuPDF` / `pdfplumber` / `python-docx` / `openpyxl`（文档解析）、
`pywebview`（Web 界面）、`winrt-*`（Windows 内置 OCR，约 4MB）、`playwright`（界面回归）。
精确版本见 [requirements.txt](requirements.txt) 与 [requirements.lock](requirements.lock)。

`global_config.json` 主要字段：

```json
{
  "model": "qwen3.5:4b",
  "privacy": true,
  "dark_mode": false,
  "topmost": false,
  "thinking_depth": 3,
  "permission": "ask",
  "custom_models": {}
}
```

| 字段 | 说明 |
|---|---|
| `model` | 当前模型 |
| `privacy` | 是否启用脱敏网关 |
| `dark_mode` | 暗色主题 |
| `topmost` | 是否置顶（默认关闭，可持久化） |
| `thinking_depth` | 思考强度 1–10（界面四档：低 2 / 中 4 / 高 7 / 最高 10） |
| `permission` | 新对话默认档位（`plan` / `ask` / `auto` / `full`），每个对话可在输入区单独覆盖 |
| `custom_models` | 自定义模型配置（密钥加密落盘，不回显） |
